# Lumi 0.1.3

发布日期：2026-10-18（预发布）。

- AI 用量新增 Qoder IDE、QoderWork、WorkBuddy、千问办公四款本地采集来源，统一进入 Lumi 的统计、软件/模型排行、会话详情及 CSV 导出。千问办公与 Qwen 编程工具独立统计。
- 数据卡片数字、趋势柱及排行加入数据变化动画；软件排行和模型明细的 Token、百分比及进度条同步过渡，快速切换可接续，支持减少动态效果。
- 修复日期弹窗选中数字偏右的问题，保持日期数字居中。
- Skills 来源分类和知识库分类显示对应数量，数量不受搜索关键词影响。
- 同步应用、Core、共享包、stdio 代理、主页 SDK 及内置模板版本；主页工程格式和桥接协议保持兼容，已有主页无需重新发布。

用量说明：只统计来源实际报告的 Token，不将 Credits 或上下文占用换算成消耗。部分 QoderWork/千问办公版本需在目标软件启动环境开启 Token 记录，缺失的历史无法补造；详见 [来源说明](../AI_USAGE_SOURCES.md)。本机 WorkBuddy 已完成真实只读验证，其余三款完成协议样例与集成测试，尚未完成各客户端版本的实机覆盖。

发行方式沿用现有 GitHub 预发布工作流：三平台原生构建、独立 sidecar 检查、安装包及许可证/校验和完整性校验全部通过后，工作流自动发布。macOS 使用 ad-hoc 签名，未公证；Windows 未配置发布者签名；自动更新未配置。
