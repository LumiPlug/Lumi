# Lumi 0.1.8 预览版

浏览器自动化扩展至 39 个 MCP 工具，配套 LumiBrowserMCP 0.6.0。新增前台切换/关闭/历史导航、悬停与双击/右键、键盘与表单状态操作；进一步支持 iframe、Shadow DOM/可访问性引用、文件选择和下载跟踪、网页弹窗、网络与控制台诊断、拖拽/触摸、整页与元素截图、PDF、表格提取和移动/弱网模拟。

上传只选择明确指定的文件，不自动提交表单。下载仅跟踪当前会话关联的项目；页面下载可能因 referrer 缺失而无法关联。iframe 和 AX 操作使用 DOM 事件，依赖真实用户事件的网站可能不兼容。诊断为按需开启，常见凭证脱敏不是完整个人信息过滤器。截图/PDF 写入 Lumi 数据目录的 browser-artifacts，单个最多 20 MiB、总计最多 100 个文件。

弹窗会中断触发动作并等待明确处理，不自动重放未完成操作。沿用页面规则、用户接管、失效引用与串行控制；没有开放任意脚本或任意 CDP 命令。

## 验证

本地待发布源码通过 506 项 Vitest、TypeScript、ESLint、主页契约以及 Rust fmt/check/clippy；插件通过 130 项测试及 ZIP 构建。真实 Chrome 与本机 MCP 测试覆盖上述主要操作。详见 [验证记录](../BROWSER_TEST_REPORT.md)。各平台 CI 和安装包状态以本次运行结果为准。

此预览版不包含工作目录中另行开发的 UI、Skills 和首页原生存储改动。主页格式 2、桥接协议 1 保持兼容。Windows 浏览器交互、多显示器缩放、所有网站框架、安装升级/卸载及真实客户端场景仍需人工验收。

macOS 为 ad-hoc 签名且未公证，Windows 无发布者签名；自动更新尚未配置。插件需要 Chrome 的 downloads 权限用于下载跟踪，尚未发布 Chrome Web Store。
