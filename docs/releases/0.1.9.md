# Lumi 0.1.9

本版整合当前分支保留的 Skills、工作台和桌面界面改动，继续兼容 Lumi Browser 0.6.0。

- Skills：44 个默认软件分类，另支持显式配置的 Open Design；共享目录去重、来源合并、有界 profile 枚举、豆包与 Reasonix 候选目录。来源归属不代表客户端已安装或已启用，也不增加 AI 用量采集来源。
- 工作台：统一 iframe/CSP 权限，支持联网、CDN、表单、下载、弹窗等，保留宿主隔离。设备能力仍受 WebView、origin 和系统授权约束。
- 存储：入口脚本前预载 localStorage/sessionStorage 兼容层，项目隔离、配额、串行写入、flush 确认和失败重试；修复 iframe 自刷新握手及旧通道回包。未 flush 的立即导航或异常退出不保证最后写入保存；不模拟 IndexedDB/Cookie。
- 界面：共用折叠搜索用于 Skills、工具、知识库及用量页，工具栏保持单行并允许分类横向滚动；默认窗口 800×600，最小 720×560。
- Windows：托盘使用深底琥珀应用图标，改善浅色任务栏可见性。
- 文档：纳入来源说明、原生存储历史验证证据和 CodeBurn 审计报告，报告路径改为仓库相对路径。

历史验证资料保留原日期和版本，不代表当前版本的新测试结果。macOS WKWebView 存储已有实机记录；Windows WebView2 存储和托盘深浅主题仍需专项实机验收。预览版签名和安装限制沿用现有发布流程。

本版合并前验证：完整 pnpm check 通过（70 个测试文件、533 项测试，含契约、类型、Lint、Rust fmt/check/clippy）；前端生产构建通过。
