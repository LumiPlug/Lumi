# Lumi 0.1.7 预览版

发布日期：2026-10-21。按现有最小补丁递增约定从 0.1.6 升级，完整 tag 由 Desktop Build 运行序号生成；只发布 preview，不覆盖旧版本。

- 纳入 Windows x64 原生应用自动化：release 模式应用、真实 standalone Core 与 WebView2，覆盖关键页面导航、语言保存及重启、工作台待办与 SDK 存储刷新/进程重启、非法写入与存储沙箱边界。
- 合成 Qoder 国际/CN 数据验证中文与带空格路径、跨根副本核对、重复扫描、部分覆盖提示、暂停和刷新恢复；补充文件预算与实时进度回归。
- 保存可直接使用发布安装包的中文 [短必测清单](../qa/windows/README.md)、[详细人工用例](../qa/windows/manual.md)、[结果模板](../qa/windows/results-template.md) 及 [自动化说明和证据](../qa/windows/automation.md)。用户无需搭建开发环境。
- 统一桌面应用、Core、shared、stdio 代理、主页 SDK 与模板版本为 0.1.7；主页工程格式 2、桥接协议 1 保持兼容。本次没有新增产品功能或宣称修复未经证实的 Windows 问题。

## 验证与未完成验收

PR #16 的 0.1.6 代码基线已在 Windows Server 2022 x64 / WebView2 131.0.2903.86 上完成 A01–A06 原生自动化；真实 JSON、日志摘要和重启截图保存在仓库。Windows 原有测试集合为 406 通过、12 项 POSIX 平台跳过，Rust 单元测试 10 项通过。本次 0.1.7 版本更新后重新运行质量检查与 Windows 原生 CI；以对应提交的实际运行结果为准，不把历史通过当成本轮完成。

自动化使用独立标识、临时合成用户目录与数据库，无真实聊天/密钥/正式数据库。原工作树并行的 Skills、浏览器存储/权限及托盘改动未混入；`packages/core/src/usage/codeburn.test.ts` 未修改。

托盘可见性/菜单、正常退出、多窗口、系统权限、真实客户端读取、安装首次启动、升级数据保留及卸载边界仍待人工 M01–M10 验收。WebDriver 验证的 SDK 持久 KV 不代表沙箱原生 localStorage/IndexedDB 已开放，也不代表正式安装包已手测。

安装包沿用现有三目标 Desktop Build 流程，检查 standalone sidecars、包内 sidecar、源码提交与 SHA256 后发布。macOS 使用 ad-hoc 签名且未公证，Windows 无发布者签名；预览包可能触发系统安全提示，自动更新未配置。不要为验收删除真实用户数据。
