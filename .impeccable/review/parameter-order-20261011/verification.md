# 外部参数序号与排序验证

2026-10-11。按用户上下排序要求，在每个参数行最前面增加序号列，序号复用 text Button 作为手柄，保持已有控件及主题。

实现支持按住序号上下拖动整行，连续重算序号，边缘滚动；取消指针、Escape 或窗口失焦时恢复拖动开始顺序。键盘支持上下方向键和 Home／End，移动后聚焦同一行的序号并滚动至可见位置。顺序更新草稿，经原有保存确认后才写入工具。行身份随排序移动，因此默认值、固定值、名称、变量、绑定、说明及本地编辑锁定保持所属行。

验证：pnpm check 全部通过，25 个测试文件、191 项测试；类型、Lint、首页契约、Rust fmt/check/clippy 通过。前端、默认标识 macOS 调试应用构建、git diff --check 通过；布局检测无发现。另用内存数据库验证 Repository 保存及重新读取后字段顺序、数值、对象、私有固定值及绑定完整保留。既有主包大小构建提示保留。

原生深色 1120×820 与 720×560：真实拖动将第一项移到第三项，原来的编辑锁定跟随到第三项，序号连续，焦点保持在同一参数的序号；Home 返回首项。窄窗口真实拖动到第四项成功，End 移至第十项；修正后键盘移至末尾的序号能自动滚入可见区。原生验证没有保存排序或修改用户参数，最后用 Home 恢复原顺序；保存按钮禁用，数据库定义哈希与验证前一致，示例仍为 v1、10 个参数。

应用已重启到最终构建，窗口恢复原尺寸，停留于示例的工具配置。UI组件中的同一参数表组合自动带有该排序功能。
