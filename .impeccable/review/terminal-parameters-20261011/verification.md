# Terminal 外部参数表验证

2026-10-11。用户指定一次性表头“名称、变量、默认值、参数说明、必填、编辑”，每个参数一行，默认选中编辑，最后为删除图标。用户确认编辑只锁定当前配置行。

实现使用语义 table 和现有 FieldGroup／FieldTitle／Input／Checkbox／IconButton，复用 ui-field-row-viewport 滚动与焦点；业务样式只设置表格列宽和间距。名称对应 schema.title，变量对应 key 和绑定 key；本地编辑开关不写入定义。新增变量避开已有 key；删除后恢复相邻行焦点，空表恢复添加按钮。默认值移除按留空处理，已有数字、布尔、数组、对象、联合类型与私有固定值保持类型和可见性。HTTP 参数配置不变。UI组件 Terminal 参数预览使用同一业务组合。

检查：pnpm check 通过，25 个文件、189 项测试；类型、Lint、首页契约、Rust fmt/check/clippy 通过。前端及默认标识的 macOS 调试应用构建通过；布局检测无发现，git diff --check 通过。保留既有主包大小构建提示。

原生深色 1120×820 和 720×560 验证：表头只出现一次，10 行默认编辑开启，取消／恢复能锁定／解锁输入和必填；错误整数默认值阻止保存并聚焦原输入，修正后可继续；新增行默认编辑选中，删除图标支持键盘，删除后焦点返回上一行。窄窗口整表横向滚动，Tab 到删除按钮会将右侧列及表头一起滚入可见区。预览中的数据修改均已放弃；数据库定义哈希与验证前相同，示例仍是 v1、10 个参数、已启用。未新增测试工具或保存测试改动。
