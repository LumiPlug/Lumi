## Terminal 运行参数三段布局与输入提示（2026-10-12，当前要求）

终端参数每行依次为独立相邻的参数名、标签、输入控件三段；标签只使用已有外部可见／不可见及必填／可选元数据。取消常驻描述，单行输入右侧垂直居中、多行输入右上角浮置问号，输入为图标保留内部空间。仅非空说明显示问号，悬停、点击、键盘聚焦显示同一共用 Tooltip 气泡，Escape 关闭；气泡使用 portal，不被滚动区域裁切，长提示可换行、滚动。说明仍供辅助技术读取，校验错误保持输入框下方可见并关联 aria-describedby。窄窗口参数名与标签保持相邻，输入占下一整行；可选折叠、默认值、私有遮蔽、校验及真实传参语义沿用。此要求取代之前将标签堆在参数名下方及常驻说明的布局，不新增业务标签。

- `GraphView`：Cytoscape.js 布局与 Canvas 渲染，主题变量映射项目/模块/概念/符号颜色；缩放、适应窗口、受控选择和关系清单。Canvas 容器宽度小于 720px 时采用紧凑网格，最多显示 6 个带标签节点，优先项目与模块并保留当前选择；关系采用曲线以避开标签。清单保留组件收到的全部节点与关系，提供键盘可操作的节点选择、关系类型和推断标记，不受紧凑图谱的 6 节点限制；Core 返回限额仍适用。Canvas 设为辅助技术隐藏，初始化失败时回退至清单。无循环动画。
- `DocumentViewer`：ReactMarkdown + GFM，禁用原始 HTML、远程图片和外部导航；正文开头与阅读标题相同的 Markdown 标题省略，避免重复。文档引用通过已登记的 `#citation-ID` 或来源按钮打开证据。

## 使用边界

工具运行复用 WindowPanel、LogViewer、Button、Field、Input、Textarea、Select、Checkbox、Segmented、Tabs、Badge，关闭确认及备用弹窗复用 Modal。准备按类型限制编辑范围，执行目标只读、仅修改已有参数值，运行后为冻结快照；“查看参数”Tab 展示完整配置与当前输入，执行后使用“本次参数”Tab。工具、技能与知识库二级页面返回复用 IconButton + ArrowLeft。知识目录标题行右侧的图谱与搜索入口复用 IconButton；搜索浮层复用 Modal、Input、Button、SurfaceButton 和既有标题／辅助正文样式，结果一行摘要只增加布局截断；搜索框固定在结果滚动区上方，同文档的节点与文档命中合并。

业务传文案、图标、值、回调、可用状态；组件持有固定视觉状态、键盘行为、原生语义与动效。无需在业务页面重写按钮／Tab／表单／提示／确认外观。`className` 仅用于所在页面的布局、宽度、位置、等宽编辑内容，不覆盖颜色、圆角、焦点或交互效果。工具类型和技能来源通过 Badge 的 `data-tool-kind/data-source` 复用 palette 中既有的专属身份配色；映射由共用组件维护；文件树、运行记录和工具卡是业务组合，而非任意皮肤。

- Button：`variant="primary|secondary|ghost|danger"`；`loading`、`loadingLabel`。两层文案始终占位，加载保留宽度并禁用重复提交；默认 `type="button"`，提交显式传 `type="submit"`。保留外部原生属性、ref、表单关联和 `aria-busy`。点击触发时先聚焦按钮，确保 Safari 指针操作后的弹窗和气泡也能恢复至触发控件；不移动滚动位置。
- IconButton：必须提供 `label`；`tone="neutral|accent|success|danger"`、`glow`。图标由外部传入 outline SVG。加载保留图标并禁用操作，状态通过可读名称和 `aria-busy` 提供。
- Tabs / Segmented：`items`、`value`、`onValueChange`、`label`。选中由业务控制，回调仅请求切换，不能绕开未保存保护。Tabs 的 item 提供稳定 `id` 和 `panelId`，业务面板设置 `role="tabpanel"` 和 `aria-labelledby`；需要恢复指定项焦点可用 `buttonRef`。数量默认可读；提供完整 `accessibleLabel` 后隐藏重复数量。
- Input / Select / Textarea：原生属性与 ref。Textarea 默认五行，`showCount` 需同时传受控字符串 `value`、`maxLength`。输入中更新计数，辅助技术通过 `aria-describedby` 读取，不逐字打断播报。
- FieldTitle：`htmlFor/label/hint/optional`，复用标题和提示图标的居中布局，适用于业务组合的配置标题。
- Field：`label`、可选 `hint/description/error`、`inline`；直接传入一个 Input / Select / Textarea。自动关联标签、错误与描述。校验逻辑、聚焦第一个错误和顶部气泡由业务执行。
- ChoiceCard：`label`、`description`、`selected` 和原生按钮属性。ThemePicker 受控 `value/onValueChange`，不自行修改全局主题或偏好。
- InputHint：`label/hint/multiline` 与一个输入控件；非空提示才显示问号，单行右侧居中、多行右上角。保留标签、描述与错误关联；定位和内部留白归共享组件。
- Tooltip：`label`、说明内容及可选 `icon="info|help"`。挂在最近的 dialog 或 body；支持 Escape、滚动与窗口变化关闭，移到提示上继续阅读。
- Modal：条件挂载，`title`、内容、`actions`、`onClose`。打开聚焦标题，或传 `initialFocus`；Safari 指针触发建议显式 `returnFocus`。`busy` 阻止关闭。actions 可传 `(close) => ReactNode`，使用该回调获得完整退出交互。退出一开始就锁住内容和操作，避免取消后再次提交。ConfirmationDialog 复用 Modal + Button，默认聚焦取消，确认动作仍由业务承担。
- SurfaceButton：供文件树、卡片点击区域等复杂组合，不提供任意颜色／尺寸参数；新增业务组合先使用标准 Button 或 ChoiceCard。NavigationButton 收敛图标侧栏的选中与提示效果。
- Card / Badge：传内容、原生属性和标准语义 tone；Card 的 `density="normal|compact|flush"` 控制既定内边距，`interactive` 控制卡片悬停和焦点边界；Card 用于有内容关系的容器，不为每个示例或字段嵌套一张卡片。

```tsx
import { Button, Field, Input, Tabs } from './ui'

<Field label="名称" error={nameError}>
  <Input value={name} onChange={event => setName(event.target.value)} />
</Field>
<Button variant="primary" loading={saving} onClick={save}>保存</Button>
<Tabs label="工具详情" items={detailItems} value={tab}
  onValueChange={next => guardUnsaved(() => setTab(next))} />
```

## 交互强度与维护

首页工作台外的业务界面采用与组件预览一致的重阴影档位；outline 图标光晕来自一份不可点击、不可播报的图形副本，固定模糊，动画只改变透明度。容器保持平整，浮层使用带偏移的柔和阴影。不使用装饰性循环或整页入场。

阴影尺寸复用 `obsidian-solar-amber.css`，阴影色在 `palette.css` 深浅映射。悬停120ms、按下100ms、展开160ms、进入180ms、退出120ms。减少动态效果时取消过渡／位移／缩放，静态选中与光晕仍可读；高对比模式保留系统焦点与选中边界。

新增组件或状态必须在开发预览中提供真实可操作示例，并同步本文及 UI_DESIGN。预览包括正常、禁用、加载、校验、深浅主题、说明、确认、嵌套浮层和真实顶部反馈。执行 CONTRIBUTING 要求的 `pnpm check`，并检查开发入口存在、正式包入口和页面代码均不出现。

## 重阴影审查预览

首页工作台外的界面与开发预览通过共享 `SurfaceEffects depth="heavy"` 使用已确认的重阴影档位；工作台内容与构建模板不受本次迁移影响。按钮常态阴影透明度为 0.6，悬停／键盘聚焦为 1，按下为 0.3；悬停上移 1px、按下回落 1px。选中 Tab、选择卡片与悬停／聚焦的交互卡片呈现重阴影，输入框聚焦呈现琥珀光晕；禁用控件不产生阴影反馈。图标继续使用 outline，底部光晕使用 8px 模糊与 6px 下移，交互时透明度为 1。

尺寸集中在主题变量：控件阴影为 `0 6px 18px` 与 `0 2px 6px`，浮层为 `0 16px 40px` 与 `0 6px 16px`；颜色由 palette 深色黑色 60%、浅色深灰 24% 映射。Modal、嵌套确认窗和 Tooltip 通过 React 上下文保留同一档位，包含 portal 内的按钮。仅动画透明度与轻微位移，不动画阴影或模糊值；保留焦点与减少动态效果支持。

## 表单预览与共用交互

`Field inline` 的标签和说明按钮在同一水平行垂直居中，使用共享 36px 高度与辅助字号／行高。单行控制区靠右，标准输入宽度上限复用 `--lumi-form-control-width`（320px），选择框按内容宽度显示并靠右；窄窗口保持最大可用宽度。多行输入继续使用全宽及至少五行高度。

Tooltip 说明触发器直接复用默认灰色、交互时琥珀色的 outline IconButton，保持 16px 提示图形、36px 点击区域与底部同色光晕，重阴影档位和减少动态效果设置同时适用；悬停、焦点、点击和 Escape 的提示行为不变。Checkbox 使用原生 checkbox 输入并配置共享 `--lumi-checkbox-size`（20px），选中填充主题主操作色与高对比勾号，保留整行点击、键盘、禁用及高对比模式的原生回退。

图标操作默认使用主题辅助灰色，悬停、键盘聚焦或按下时显示对应语义色与底部光晕；禁用状态保持灰色。共用 IconButton 移除浏览器原生按钮外观并明确允许绘制溢出；光晕层在图形四周预留两倍模糊半径的绘制空间，SVG 及内容层允许溢出，避免重阴影档位的光晕左右被裁切。

## 业务采用与强制规则

首页工作台以外的所有新增或修改 UI、视觉与交互，必须从 `src/components/ui/index.ts` 复用共用组件，以开发预览为基准。业务仅传文案、图标、数据、回调、状态和必要布局，不覆盖同用途的颜色、圆角、阴影、焦点与动效。组件或现有状态不足时，必须先向用户说明缺口并确认；确认前不得自行创建新组件、新视觉或临时页面样式。确认后先更新组件与真实预览，再接入业务并同步规范。

工具、技能、设置及相关浮层统一继承重阴影；36px 控件、默认灰色交互语义色的 outline 图标、16px 提示图形、20px 主色 Checkbox、紧凑靠右的单行 Field 均来自共用实现。滚动列表复用主题的阴影留白，避免卡片阴影在两侧截断；独立图标操作不同时激活整张卡片的阴影。正式构建保留共用效果而移除开发入口及预览页。

工具新增／运行和知识搜索复用 Modal，可通过 `className/bodyClassName` 传入尺寸及滚动布局，`header={null}` 与 `titleId/initialFocus` 或 `initialFocusSelector` 保留业务标题，内容可传 `(close) => ReactNode`；工具与技能详情使用整页二级布局。需要未保存确认的编辑器传 `requestClose` 由业务先决策，取消离开时不进入退出动画或锁住编辑区。此类组合只改变布局，不另定义浮层视觉。

ESLint 在首页工作台及组件实现之外禁止直接写原生 button/input/select/textarea/dialog；仅此检查不能替代视觉审查，布局与样式仍需遵守以上规则。ToastProvider 因模块循环直接引用共用 SurfaceButton 的实现，其效果仍来自同一组件。

## 选中与键盘焦点

共用按钮、Tab、Checkbox、选择卡片、主题卡片及可聚焦内容卡保留真实焦点与恢复焦点行为。SurfaceEffects 共用一份输入方式监听，pointerdown 后隐藏这些控件的额外焦点描边；Tab、方向键、Enter 等键盘操作恢复可见焦点。输入框仍保留鼠标聚焦后的编辑反馈。监听按引用计数管理，嵌套预览卸载不影响业务；Portal 自动采用同一输入方式。

共用控件的 2px 焦点描边使用共享 `--lumi-focus-outline-offset: -2px`，叠于边框内侧，不额外增加外圈。选中与键盘焦点同时存在时，维持单层 2px 边界并使用既有 `--lumi-shadow-focus-heavy` 光晕；选中状态仍有勾号、主色或原生语义。强制颜色模式用同宽虚线保留可区分焦点，不依赖阴影。设置与 UI组件预览使用同一实现。
