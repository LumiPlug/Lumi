# 界面语言

2026-10-19 用户确认：设置支持简体中文（zh-CN）与 English（en），默认保持简体中文。语言选择复用设置行与共用 Select；自动保存后即时生效，无需重启，不重建页面、不清空输入或中断任务。选项始终用本语言名称，字段显示“语言 / Language”。保存失败使用顶部错误 Toast，保留原选择。

语言资源集中在 src/i18n；界面源码通过类型化翻译函数读取固定文案，插值保持原始数据，禁止对 DOM、用户正文或日志做自动替换。日期与普通数字跟随语言；协议、ISO 日期、内部 ID、技术名与既有 K/M 计量缩写保持稳定。共用组件的空态、提示、辅助技术标签也纳入翻译。

桌面宿主持久化语言偏好；主窗口允许修改，工具运行窗口只读取并通过事件同步。新建与隐藏后重建的 WebView 在首屏加载前获得宿主语言；托盘和应用自行提供的原生标题跟随语言。浏览器开发预览用 localStorage 保存及 storage 事件同步。语言状态使用订阅更新，不使用按语言改变 React key 的重新挂载。

既有自定义工作台 HTML、用户名称、知识正文、导入的技能说明、第三方响应与原始日志不改写；宿主工作台引导与内置搭建提示词提供双语。

验收包括语言资源键/插值一致、设置中切换与保存失败、重新启动/多窗口同步、状态与输入保留、主要页面及弹层双语、双主题/窄窗口/键盘操作。代码修改运行 pnpm check；设备验收与未覆盖范围记录于本次 QA 报告。

## 实现与维护（2026-10-20）

- `src/i18n/zh-CN.json`、`en.json` 维护双语固定文案；采用源语言文本作类型化键。新增或修改键时同时更新两份资源，插值统一使用 `{v0}`、`{v1}` 等命名参数。英文需要单复数时可用 `{v0|tool|tools}`，按 `Intl.PluralRules` 选择。
- 显示翻译的 React 组件通过 `useLocale()` 订阅，使用 `t()` 读取文案。模块级标签表通过 getter 在读取时翻译，禁止模块加载时固化翻译结果。不要通过语言 key 重新挂载界面，也不要为了语言变化重新请求业务数据。
- `translateKnown()` 仅用于已知宿主错误与应用产生的反馈，允许已有 Toast/字段错误跟随语言更新；不得用在名称、正文、日志或任意第三方返回上。内部数据结构保持稳定，技术预览的展示键只在呈现时翻译。
- 原生通过验证 nonce 的 `get_ui_locale`、`set_ui_locale` 读取/保存，只有主窗口允许修改；磁盘保存成功后提交内存状态并广播 `lumi-locale-changed`，存储失败保持原语言。窗口初始化脚本预载当前语言，避免新窗口先显示默认中文。
- 设置自动保存期间锁定选择并保持宽度，完成后仅在焦点没有移向其他控件时恢复选择框焦点。成功/错误分别复用 4 秒/8 秒的顶部 Toast。

验证结果及平台边界见 [验收记录](qa/2026-10-20-localization/README.md)。
