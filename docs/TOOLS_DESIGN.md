# 工具内容页设计

## Terminal 运行参数左右布局（2026-10-12，当前方案）

运行参数改为逐行左右布局，移除五列表头。左侧显示实际参数名，下面用共用 Badge 展示“外部可见／外部不可见”和“必填／可选”；右侧为共用 Input，参数值仍可编辑。描述只在非空时通过参数名旁的共用 Tooltip 说明图标呈现，悬停、点击或键盘聚焦显示完整描述；气泡跟随现有主题、边界适配和 Escape／滚动关闭规则，不在业务层覆盖视觉。

列表继续复用左对齐 Card 背景、288px 固定高度和内部垂直滚动；正文内不再需要横向浏览五列。每行右侧输入占较多宽度，左侧长参数名和 Tag 可换行；列表内容宽度不足 420px 时输入移至信息下方。参数名用 label 关联本行输入，错误说明保持 aria-describedby 与首个错误聚焦。执行后的配置及详情使用同一左右布局展示只读快照。本次仅调整运行 UI，工具配置页的参数编辑表、真实参数契约、手动覆盖接口、私有值遮罩、工作目录和两个运行节点沿用既有行为。本节替代运行参数五列文本展示方案。

## Terminal 运行配置与工具配置统一（2026-10-11，当前方案）

终端运行窗口的配置节点直接展示工作目录、外部参数表，复用工具编辑页的 TerminalWorkingDirectory 与 TerminalParameterTable 业务组合。工作目录沿用 inline／wide Field、revealEnd Input、选择文件夹和图标说明；留空使用用户主目录。参数表沿用左对齐 Card 背景、外部可见／参数名／参数值／描述／必填五列及 288px 内部纵向滚动，窄窗口在表内横向浏览，外部可见和必填文本与标题水平居中。

本次运行仅编辑目录和参数值；参数名、描述、外部可见、必填直接以文本展示已保存配置；两项布尔状态显示“是／否”，描述换行显示完整内容，不提供增加、排序与删除。所有参数值使用可编辑 Input；数组／对象使用单行 JSON，布尔输入 true／false，枚举填写其已有值，继续通过真实参数 Schema 校验；私有固定参数使用密码输入。校验失败聚焦实际参数值并关联错误说明，通过顶部 Toast 提示。开始运行后，配置展开与详情均以同一表格只读展示冻结的本次输入；调整后再运行保留输入。目录与固定值仍通过既有手动覆盖接口提交，不保存工具定义、不改变 AI 参数契约。HTTP／MCP 继续沿用原有表单。终端“查看技术信息”收进外部参数标题行右侧，取消空的“更多设置”层级；目录在运行节点中取消工具编辑页的额外上下外边距，让两个节点保持紧凑。运行表移除操作列后，最小宽度为两倍共用字段宽度（640px），标准 760px 窗口展示全部五列。提供恢复默认值／固定值及不提供可选参数的既有操作。本节替代终端逐字段纵向表单方案。

## 共用整行拖动状态（2026-10-11，用户确认扩展）

ui/index 导出 useTableDragPreview，供排序组合使用。按住手柄时复制当前行的视觉快照，保留输入框正在编辑的文字、勾选状态及固定值遮罩；浮层不可点击、不可聚焦、不参与表单提交或辅助技术树，移除重复 ID 与校验目标。实际输入控件保持挂载，不因浮层重新创建而丢失草稿。浮层复用主题面板背景、8px 容器圆角与浮层重阴影，并限制在参数表的横向可见区域。

原行保留布局高度，显示共用虚线占位框，内部内容暂时隐藏；浮层跟随指针纵向移动，整行顺序实时更新。自动滚动时浮层仍跟随指针，占位在实际落点；松开后按共用 100ms 按下时长回落，再移除浮层并恢复手柄焦点。Escape、指针取消、失焦或窗口尺寸变化恢复原顺序并清理浮层；卸载立即清理。减少动态效果时直接落位，高对比模式保留系统边界与占位线。键盘排序保持既有方向键与 Home／End 行为，不生成浮层。UI组件中的 Terminal 参数组合展示同一拖动效果。

## 共用滑块开关（2026-10-11，用户确认扩展）

Switch 由 ui/index 导出，接口为 label 与原生 checkbox 属性；使用 checkbox input + role="switch"，保留表单关联、标签点击、Tab／Space 操作、ref、禁用及辅助说明。轨道宽度复用控件高度，轨道高度复用 checkbox 尺寸，圆角沿用 4px 控件规范；滑块位置区分开关状态，开启使用主操作色。颜色、焦点、重阴影、120ms 轻微滑动、减少动态效果和强制颜色支持由共用层维护。UI组件交互控件页面提供真实开启／关闭和两种禁用状态，终端参数必填使用同一组件。业务不单独定义开关视觉。

## Terminal 外部参数表（2026-10-11，当前方案）

表头文字为“外部可见、参数名、参数值、描述、必填”，删除列无可见标题。拖动图标与外部可见勾选框仍在同一单元格水平排列，必填共用 Switch 独立成列且不重复标签，删除 IconButton 位于末列。鼠标悬停或键盘焦点进入参数行，以及正在拖动时，才显示该行的拖动／删除入口；业务通过原生 hidden 状态控制显隐，预留 36px 图标位置，保持输入框布局稳定。未激活行仍可从外部可见及输入框进入，焦点进入后可用 Shift+Tab 访问前方拖动手柄；焦点仍在行内时不隐藏控件。取消序号及参数值内的可编辑开关；全局只读或忙碌时统一禁用。

列表背景复用 Card density="flush"，背景外框与“外部参数”标题左边缘对齐；背景、边界、8px 圆角均由共用组件提供，业务仅安排容器宽度与内容布局。

外部参数列表高度固定为 8 倍共用控件高度（288px），超过高度时只在列表内部纵向滚动；窄窗口保留同一区域的横向滚动，滚动条预留空间。参数数量或输入错误不会撑高列表。列表滚动时重新匹配鼠标所在行，显隐跟随实际指向位置。拖动时优先在此视口的实际可见上下边缘自动滚动，小窗口按外层表单裁剪范围计算触发边缘；浮层横向裁剪避开垂直滚动条。

“外部可见”标题移除说明图标；勾选框本身与标题共用列的水平中轴；拖动图标独立定位于同一单元格左侧预留位置，第一列宽度为3倍控件高度（108px），避免组合占位把勾选框推向右侧。勾选框对应字段 aiVisible。关闭时把当前公开参数值移入内部固定 value 并移除 Schema default；开启时把固定值转为公开默认值，保留原类型。参数名编辑字段 key 和绑定 key，描述编辑 Schema description；既有 Schema title 元数据保留。公开参数值编辑 Schema default，内部固定参数值编辑 value 并使用密码输入框。留空移除公开预设，数字、布尔和 JSON 保留类型。

拖动手柄复用 text Button + GripVertical，按住时整行浮起并显示占位，上下拖动并在松开时落位；靠近内容边缘时自动滚动；键盘方向键或 Home／End 调整顺序，Escape、指针取消或窗口失焦恢复原顺序。行身份、未完成输入、可见状态、参数值及必填状态随整行移动。操作只修改草稿，保存后才写入工具。删除复用 IconButton + Trash2，焦点移至相邻行，删除最后一行后回到添加按钮；HTTP 参数配置保持既有行为。

结构使用语义表格，控件复用 FieldGroup、FieldTitle、Card、Input、Checkbox、Switch、Button、IconButton；业务 CSS 只安排列宽、间距和拖动光标。表头与参数行使用同一共用滚动视口，窄窗口可横向浏览；保持 36px 控件高度、现有重阴影、主题与键盘焦点。UI组件中的 Terminal 参数预览复用同一组合，自动展示最新布局和交互。本节替代此前含名称、序号和本地编辑锁定的布局。

## 配置／执行两节点（2026-10-11，当前方案）

2026-10-11 紧凑布局修订：移除运行窗口及运行弹窗标题右侧的 ×，独立窗口通过原生窗口控制关闭，内嵌弹窗保留 Escape 和原有关闭保护。两节点间距为 12px，节点正文距标题 4px，取消 28px 左侧缩进，配置字段与执行内容共用窗口正文的左右边界。参数复用 Field 的 inline／wide 布局，标签与控件同行；窄窗口按共用组件规则回到上下排列。节点控件保持共用组件的 36px 最小高度、字号、状态和焦点效果；只调整业务布局。

## 普通用户运行流程（2026-10-11，当前方案）

独立运行窗口默认直接显示工具用途、可填写内容与“开始运行”。Terminal 移除一次执行／持续执行选择，沿用工具的 run 操作；仅有单个其他操作时沿用该操作，不改变执行器、停止能力与 AI 调用接口。参数名称优先使用 Schema title，说明直接显示，数值使用普通输入框，布尔值显示是／否。

请求连接与技术配置通过“更多设置”展开，完整配置只在“查看技术信息”中呈现；保持原有编辑范围。无输入时明确提示可直接运行。终端运行内容直接展示，不再出现内容切换 Tab；HTTP/MCP 在结果与运行记录之间切换，结果优先使用共用 DocumentViewer 阅读排版，原始数据可按需查看。当前输入由次级按钮查看，历史记录明确告知未保留输入，不展示当前定义冒充历史。修改后重新运行仍先回到准备，不立即执行。

## 阶段式运行弹窗（2026-10-06，历史方案）

用户确认固定高度的纵向两节点方案：正文为“配置 → 运行”，删除结果节点。主弹窗 760×680（共用变量），视口不足时约束尺寸；标题与底栏固定，正文滚动；运行日志使用固定高度的内部滚动区。标题右侧为类型 Tag；无独立参数弹窗、重复取消或关闭按钮，×/Esc 退出且运行任务继续。

StageSection 当前节点为黄色实心圆；已执行为绿色实心圆；失败为红色实心圆；运行中为黄色外圈与旋转内环。文字状态同步说明，减少动态效果时内环静止。配置执行后支持键盘展开／收起，未开始的运行节点弱化；运行开始及结束后保持展开，真实状态通过标记与文字说明，不另建结果阶段。

运行节点采用共用 LogViewer：240px 固定高度、左侧行号、内部纵向滚动，首次展示、输出更新及视口尺寸变化自动置底。用户可上翻查看，后续输出到达时继续自动置底，不关闭自动跟随，不再显示“回到最新”。只改变日志内部滚动位置，不逐行移动整页或抢焦点。Terminal 展示 stdout 与带 [stderr] 前缀的错误输出（按流分组，不声明跨流时序），结束后不重复输出；HTTP/MCP 展示实际执行事件，最终响应在结束后接到同一日志区。日志下方保留耗时、退出码／HTTP 状态、复制输出及错误详情。失败状态只由运行节点标记和文字说明，不重复状态 Badge。

配置节点展示目标摘要与本次公开参数，复用 Field/Input/Select/Textarea 编辑必填、可选和默认值；MCP 多操作与 Terminal 执行方式也在此选择。私有固定配置不暴露。修改只进入本次调用，不保存工具定义；无“仅影响本次运行”和无参数提示。运行后展开配置可查看冻结的实际公开参数与来源。点击运行完成预检，失败时聚焦首个错误字段并通过顶部 Toast 说明；输入保持。终态仅提供“重新运行”：点击后重置配置／运行节点的状态，保留本次操作与所有已填参数，清除当前任务关联、快照、日志、错误、耗时、复制状态及展开状态，回到可编辑配置并恢复焦点；等待用户再次点击“运行”。

底栏准备为运行，提交锁定重复操作，执行为危险语义停止，终态为单一主按钮“重新运行”。当前后端无暂停／恢复，统一真实停止；HTTP/MCP 远端执行未知时保留说明；重新运行仅重置页面，实际再次执行须点击“运行”，不会触发同会话任务重放。旧任务仍保留在运行记录。键盘与主题规范沿用共用组件。

共用组件在设置 UI组件预览中展示：StageSection 执行标记、两节点组合、LogViewer 固定高度行号日志与追加输出自动置底。业务只组合导出组件与布局，不改品牌原文。

| 草稿             | `status=draft`，未授权                       | 完善配置           |

## 4. 创建、编辑与整体授权

### 创建

1. 点击“新建工具”，在详情区进入创建表单，先选连接方式：Terminal（运行本机命令）、HTTP（请求接口）、MCP（连接上游工具服务）。选择本身不创建记录。
2. 填写名称、用途说明和该类型的基础配置；高级区域提供命名空间、参数与输出。名称当前为技术标识：英文字母开头，最多 64 字符，允许字母、数字、`.`、`_`、`-`。不用中文占位示例误导用户；中文用途写入描述。独立中文显示名留后续模型扩展。
3. 主按钮“保存草稿”，允许连接配置尚未完整，必须满足 canonical 结构。保存后停留详情、顶部气泡反馈、状态显示草稿。未保存离开时提供“继续编辑／放弃修改”的必要决策。
4. 保存时自动校验配置格式、字段绑定与必需值，失败时标记并聚焦首个错误字段，通过顶部气泡说明问题；详情和新增表单不提供独立“检查配置”按钮。真实 MCP 发现仍使用独立的读取入口。

默认命名空间沿用 `local`，但界面持续预览完整公开名，如 `local.run`。同类默认名可能冲突，启用前提供可编辑命名空间并明确指出冲突操作；不静默覆盖，不自动改公开名。`Lumi` 保留；公开名最长 128 字符。

### 编辑

“配置”先只读展示，点击“编辑”进入表单。编辑中的本地输入不影响已保存版本；取消恢复已保存内容。保存已启用工具前明确提示“保存后将暂停新调用，需重新授权”；按钮写“保存为草稿”，成功后回到草稿状态。MCP、工作台和手动入口同时停止接收该工具的新调用，已有任务继续按启动时的版本快照运行，并单独提供停止操作。

需要新增完整定义读取／保存接口、版本条件更新和执行配置校验。保存带读取时版本，冲突时保留本地输入并允许查看最新版本，禁止静默覆盖。第一阶段不设计“草稿和已启用版本并行运行”的第二份配置。

### 整体授权与启停

配置完整且对应执行器实际可用后，显示“审阅并启用”。同页审阅区列出用途、真实执行范围（如可执行动态 Shell 命令）、本地目录或目标服务、全部操作、AI 公开参数、内部固定字段与允许返回内容。用户一次点击“授权并启用”，作用于整条工具及所有操作；不设逐操作开关。启用不自动运行。

启用后说明“可在这里运行，也可通过 Lumi MCP 调用”；AI 客户端需刷新工具目录，不能声称客户端已同步或持续在线。重新启用同样审阅当前完整配置。AI 不能授权或启停。

“停用”立即阻止新调用，不额外确认普通停用；已有任务保留并明确提示“现有任务仍在运行”，用户可逐个停止。停用与停止任务不是同一操作。以上任务行为随 Task Manager 实现；现有 API 只改变记录状态。删除、批量授权、导入导出不进入首轮。

## 5. 三类配置与公开参数

共享表单先呈现用途，再呈现执行配置，最后呈现参数与 AI 预览；高级 Schema 编辑折叠。保存、校验及启用共用 Core 校验规则，不在 UI 复制另一套判断。

| 类型     | 基础配置                                                                          | 参数、操作与结果                                                                                                      | 边界                                                                                                                              |
| -------- | --------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------- |
| Terminal | 工作目录；Shell 默认自动；高级环境变量键值                                        | 运行页输入命令／脚本。后续支持一次执行、后台启动、状态、日志、停止和重启                                              | 当前只有 `run` 草稿定义；需补进程组终止、超时、任务与日志。命令是运行输入，不另造固定命令字段                                     |
| HTTP     | URL、Method（GET/POST/PUT/PATCH/DELETE）、超时（模型默认 30 秒）；高级固定 Header | 参数逐项定义名称、类型、说明、是否必填、来源和 path/query/header/body 绑定；配置允许返回字段，预览最终公开输出 Schema | 当前只有空 `input`／空输出 Schema；绑定校验、请求预览、响应允许列表裁剪与真实请求均待实现。不得用公开输出 Schema 冒充完整响应保护 |
| MCP      | stdio：命令、逐项参数、环境变量；Streamable HTTP：URL；仅展示所选传输相关字段     | “连接并读取操作”获得真实名称、说明和 Schema；映射到本工具命名空间，预览所有将开放的操作                               | 握手、发现、转发和重连均待开发。HTTP 上游鉴权 Header 当前模型没有，需先扩展模型；不画出无法保存的字段                             |

MCP 发现需要真实启动进程或访问上游，因此按钮旁解释其行为；它不授予 AI 使用权限。失败保留配置与已保存目录并标记待复查，绝不以占位 `call` 代替发现结果。上游新增操作或 Schema 扩大需重新审阅整体配置，第一版暂停该工具的新调用并转草稿；消失操作立即不可调用，进行中任务仍按原快照处理。该变化策略需新增版本与会话逻辑，不是当前行为。

字段的来源使用明确的二选一，而不是单独一个难懂的“可见”开关：

- **调用时填写（AI 可见）**：名称、说明、类型与必填规则进入公开 Schema；手动运行者填写同样参数。映射 `aiVisible=true`、`value=null`。
- **固定配置（AI 不可见）**：用户填写固定值，只由 Core 执行时补入；字段名、值和绑定均不进入公开 Schema。映射 `aiVisible=false`、`required=false`；“固定值是否完整”由本地配置校验判断，不复用 AI 必填标记。

切换来源不静默丢弃固定值；提交前说明并确认清除不再适用的值。敏感值默认遮蔽，可由用户显式查看；不额外创建 Secret 系统。“AI 不可见”只说明接口可见性，不宣称磁盘加密。隐藏值可能被上游响应或命令输出回显，执行层必须处理结果／日志／错误的泄漏边界，预览本身不能保证这一点。

“AI 可见预览”由 `deriveAiToolView()` 派生，显示公开名称、说明、输入和输出 Schema；不从完整定义先序列化再删除字段。配置名、公开说明和 Schema 都可能公开，辅助说明提醒不要在其中填写私密值。UI 完整配置与 AI 预览严格分开。

## 6. 运行、测试与记录

**“运行”是一级操作，手动执行与 AI 调用走同一 Registry。** 不另建浏览器直连 HTTP、直接 Shell 或第二套 MCP 客户端执行链。人工运行也仅提交公开输入，内部固定值在配置中修改。

- 一条工具含多个操作时先选操作；只有一个时省略选择器。表单由公开 Schema 生成，复杂 object/array 提供有标签的 JSON 编辑输入，提交同样校验；Terminal 优先用多行命令输入。
- 主按钮“运行”；Terminal 长期任务另提供“后台启动”，待后端实现时开放。进入页面、选择操作与按普通 Enter 均不自动执行；多行输入 Enter 换行。
- 点击后固定按钮宽度并显示“提交中…”，拒绝重复提交；任务建立后显示任务标识、起始时间、耗时和状态，提供“停止”。状态采用后端事实：准备中、启动中、运行中、已完成、失败、已取消、超时。
- 点击停止后显示“正在停止”，等待后端确认再显示已取消。Terminal 必须结束进程组；HTTP/MCP 无法确认取消时说明“已请求停止，服务端执行结果未知”，不能伪报回滚。自动重连不重放有副作用的调用。
- 切换工具或离开页面不停止任务；返回恢复任务状态。重启应用后从 Core 查询，无法恢复时显示中断／状态未知，不补造成功状态。

结果区是执行产物查看器，提供文本／JSON；Terminal 展示 stdout、stderr 与退出码，HTTP 展示裁剪后的响应及可公开状态码，MCP 展示允许返回的结构。图片、文件与导出需 Artifact 接入后开放。大结果按大小限制截断并明确标记，日志增量 cursor、窗口化／虚拟化显示，支持暂停自动跟随；不在页面内无限追加日志。

“测试”不做一个暗中绕过授权的入口：真实试运行在启用后使用同一“运行”表单，明确它会产生真实效果。草稿只可检查配置及进行必要的上游发现；不实现草稿单次授权，避免新增第二套权限机制。测试成功仅说明该次调用完成，不自动启用、不保证所有参数都可用。

“记录”按工具列出真实任务：时间、操作、调用来源（手动／AI／工作台）、配置版本、状态、耗时。只在有任务存储后出现；不把配置快照显示为运行历史，不识别无法可靠获得的 AI 客户端姓名。首个执行版本至少保存任务元数据及可恢复的近期日志；保留上限、日志滚动和结果过期由 Task/Artifact 实现明确，UI 对已清理内容显示“日志已过期”。不默认持久保存完整输入或私密配置。记录详情可复用允许公开的输入再次打开表单，但必须由用户再次点击运行。

操作成功、失败与校验说明统一用顶部 `useToast`；结果区只展示任务状态与产物，不追加“运行成功”等操作反馈横幅。失败详情可持续显示错误码、发生阶段与恢复动作，内容必须经过标准化，不含完整 URL、Header 或隐藏值。网络故障不标红参数；字段错误聚焦首个字段并附辅助技术描述。失败重试始终由用户主动触发。

## 8. 与其他页面的关系

- **工作台**：面向用户定制的快捷操作和结果展示；工具页负责配置、直接运行与诊断，两处调用同一 Registry 和任务。不在此自动生成、覆盖或修改工作台。
- **Skills**：指导 AI 的标准文件资源，技能脚本不自动变成可执行工具；不在工具列表混入 Skills 或读取其文件来伪造工具。
- **设置中的 MCP**：配置“外部 AI → Lumi”的入口；这里的 MCP 工具配置“Lumi → 上游服务”。使用明确方向说明，不能共享或误用 Lumi 会话令牌。
- **内置 `Lumi.*` 操作**：目前由系统提供，不属于用户可管理 Capability；首轮不混入用户列表、不提供停用按钮。它们可运行不代表三类用户工具已能执行。
- **Memory**：本轮隐藏导航，不在工具页新增替代入口；后端规划不因此删除。
