# Windows 详细人工用例

每项结果写入 [结果模板](results-template.md) 的对应 ID。默认均为 **未执行**；只有操作者实际验证后才改状态。每条附截图/录像相对路径，例如 `evidence/M02-tray.png`；失败附时间和实际结果，阻塞附缺少的前置条件。优先级 P0 必测，P1 扩展。不要上传令牌、真实聊天、SQLite 或隐藏配置。

## M01 · P0 · 安装与首次启动

- 前置：Windows 10/11 x64 测试账户；下载发布页安装包及校验信息，记录包名、版本与 SHA256（PowerShell `Get-FileHash <安装包>` 或系统可用校验工具）。已有日常数据先保留，不在日常账户做卸载测试。
- 步骤：双击安装包，记录 SmartScreen/签名/UAC 提示；核对来源，按自己的系统权限决定是否继续，不关闭防护。完成后从开始菜单打开。若提示安装 WebView2，走微软官方安装流程。等待设置 Core 已连接；逐个打开工作台、工具、Skills、知识库、AI 用量，缩到 720×560 再恢复。
- 预期：安装流程可完成；无空白窗口/崩溃；Core 连接；页面能使用，窄窗口主要操作可达。阻止安装时记录提示为阻塞；不要声称无签名提示。
- 记录：M01，安装步骤截图、首屏和设置状态，Windows/WebView2 版本；状态：未执行。

## M02 · P0 · 托盘、关闭重开与退出

- 前置：M01；通知区域允许查看隐藏图标。
- 步骤：展开隐藏图标找到 Lumi；右键菜单逐项检查工作台、AI 用量、Skills、知识库、设置及 Core 状态。点击导航项确认到对应页。关闭主窗口（X），确认进程与托盘仍在；用托盘重开并确认恢复。重复关闭/重开两次，再最小化后重开。最后用托盘「退出 Lumi」，等待 10 秒，确认托盘消失，开始菜单重新启动正常。
- 预期：托盘可识别，菜单可用；关闭主窗口不等于退出；重开恢复、取消最小化并聚焦，不生成重复主窗。明确退出停止该实例及其 Core，无孤儿导致下次端口冲突。
- 记录：M02，菜单和重开录像、退出前后任务管理器（遮个人信息）；状态：未执行。

## M03 · P0 · 双语与适用的多窗口

- 前置：创建 M06 的安全 Terminal 工具；应用已连接。
- 步骤：设置中文→English，检查导航、设置、托盘菜单；返回工具打开运行窗口，运行 `echo Lumi-Windows-QA`。主窗切中文，观察运行窗标题、控件和任务结果；关闭主窗，从托盘重开，确认运行窗仍可访问。分别关闭运行窗和主窗再重开。保存英文，明确退出后重新启动；最后改回所需语言。
- 预期：应用自有文案同步，重启保留语言，日志原文不翻译；语言切换不清空任务或输入；主窗与任务窗独立可访问。系统标准对话框跟随系统语言、自定义主页内容不自动翻译。新进程双开行为未承诺单实例，不要求同时开两个独立应用。
- 记录：M03，中英文菜单、运行窗口和重启截图；状态：未执行。

## M04 · P0 · 工作台 WebView2 与持久化

- 前置：专用测试账户的空工作台。已有自定义主页时只测试现有主页，不换模板；无安全副本标阻塞。
- 步骤：在工作台内置流程选择「通用办公」。添加 `Windows QA 待办`、勾选完成；切到设置再回来。使用工作台现有刷新入口（若无主页刷新按钮则关闭主窗从托盘重开），确认待办；明确退出再启动确认保留。保留待办供升级检查。输入空待办观察校验；服务不可用时只观察既有错误/重试说明，不改配置或数据库制造故障。
- 预期：页面连接成功；待办和完成状态保留，无重复；输入无效时焦点/顶部错误提示合理。服务未连接不能伪装保存成功。当前正式 SDK 持久存储为 `lumi.storage`，沙箱内原生 localStorage/IndexedDB 并未承诺成功；自定义旧主页若依赖它们应记录兼容性问题，勿据此清空真实资料。
- 记录：M04，刷新/退出前后同一待办截图，实际刷新方式；状态：未执行。超限/非法键拒绝由 A03 自动验证，无需打开开发工具。

## M05 · P0 · MCP 与托管 Skills

- 前置：M01；电脑已有可接 MCP 的客户端时使用其测试配置；没有客户端时 MCP 联调子项记阻塞，不为本次测试搭建开发环境。技能样例可从本仓库网页下载 `fixtures/windows-qa-skill/SKILL.md` 与 `note.txt` 到同一新目录。
- 步骤：设置打开 MCP 详情，用内置检查/复制配置功能；在客户端建立单独测试连接，只读取 Lumi 工具列表/上下文，不请求执行真实任务。Skills「从本地安装/导入」选择样例目录，预览主文件与附件；搜索名称；归档后确认默认列表/客户端可发现集合不再出现，恢复后重新读取。再导入同源观察重复提示。
- 预期：MCP 可连接并发现 `Lumi.*`；技能内容完整，附件只在技能内可读；归档可恢复，同源重复不覆盖；原目录不变，脚本不自动执行。复制操作有顶部气泡。截图不得包含 MCP session token。
- 记录：M05，客户端名称/版本、脱敏连接状态、技能预览与归档截图；状态：未执行。

## M06 · P0 · Tools 基本使用与隐藏配置不回显

- 前置：M01，测试账户；全程只用合成假值，不填真实凭证。
- 步骤：新建 Terminal 工具 `Windows_QA`，固定命令 `echo Lumi-Windows-QA`；Windows 默认 cmd，无需额外依赖。配置用途后保存草稿→审阅→启用→运行，检查独立窗口和运行记录。将测试工作目录设成自己创建的 `文档/Lumi QA 中文`（用目录选择器），再运行。编辑后不保存尝试离开，检查未保存保护。归档/恢复，确认恢复需重新授权。
- 隐藏子项：再建一个不执行的 HTTP 草稿，地址用 `http://127.0.0.1:9/qa`，不可见 Header/参数值填 `FAKE_PRIVATE_WINDOWS_QA`。在本地完整配置应可审阅；在外部 MCP schema/管理返回与公开能力列表中不应出现该值。无需发送 HTTP 请求。已有客户端可让其只查询工具定义并贴出脱敏结果；没有可用客户端时此子项记阻塞。不要把“本地设置里看得见”误报为公开泄露。
- 预期：草稿不自动执行；启用后命令成功输出且历史可读；中文空格目录正确；保存/归档保护生效。不可见值不向 AI 公开；这不代表磁盘加密。失败路径可将命令改为 `exit /b 7`（重新保存授权），运行应失败且可看退出结果；不会把失败标为成功。
- 记录：M06，成功/失败输出、工作目录、脱敏公开 schema 证据；状态：未执行。

## M07 · P0 · Windows 用量读取、刷新、去重

- 前置：M01。测试账户无客户端记录可先验空态；有本地客户端时仅只读观察现有记录，不为测试发送新付费请求。不能公开真实会话内容。
- 步骤：打开 AI 用量，记录软件筛选、时间范围、总数与最近更新；手动刷新，观察扫描中→完成/部分覆盖，以及发现/读取/缓存/超限等真实说明。使用相同范围连续刷新两次并重启，比较不变源的合计。分别选择 Qoder 国际/CN 本机可发现数据，检查会话列表、分页、详情返回和筛选保留；有 CSV 导出时保存到测试目录并核对当前范围。
- 预期：扫描反馈不虚构全量完成；已知相同请求不重复累计；无客户端是 0/未发现，不是读取失败；缺失用量仍显示未知；暂停旧状态在手动刷新后恢复（当前 UI 没有独立暂停按钮，不要求寻找）。真实 Qoder/SQLite 与 JSONL 不能确认身份时允许提示可能重复，不强求数字猜测合并。
- 记录：M07，前后范围/合计/扫描提示，客户端版本及来源是否存在；状态：未执行。无来源时真实读取子项记阻塞；Qoder 合成去重和 API 暂停/恢复已由 A04/A05 验证。

## M08 · P1 · 真实权限/部分扫描与长运行

- 前置：有自然发生的权限拒绝、大文件或使用中源，且不需要改真实文件权限。没有该条件就阻塞，禁止为了验收破坏源数据。
- 步骤：刷新并观察部分覆盖提示；保留上轮数据仍可查询。切页面/最小化约 2 分钟再恢复，确认扫描更新与交互恢复。留意大量目录时能否取消当前 UI 操作或继续导航，不要求超过既有扫描预算。
- 预期：限制/失败被诚实报告；不清空上次成功账本、不显示假 100%；定时扫描不重复刷屏提示，不明显卡死。
- 记录：M08，脱敏提示和恢复录像；状态：未执行。

## M09 · P1 · 升级数据保留

- 前置：专用测试账户，已验证过的旧发布包与本次新包；不得降级/替换日常正式环境。只有同一包时阻塞，不伪称升级。
- 步骤：旧版本创建合成待办、安全工具与导入样例技能，选语言；明确退出。用较新官方安装包覆盖升级，重开核对上述数据、授权状态、运行记录、语言、MCP 连接配置。只用合成资料；MCP token 不上传。
- 预期：升级成功，数据与工作台保持；若产品要求重新授权需明确反馈，不悄悄执行任务；安装目录变化不误删用户数据。
- 记录：M09，两个完整版本/校验值、升级前后截图；状态：未执行。

## M10 · P1 · 卸载边界与安装方式

- 前置：专用 Windows 测试账户，确认该账户只有合成测试数据。日常账户跳过此项并记阻塞。
- 步骤：明确退出；系统「已安装的应用」卸载。逐字记录是否提供清理数据选项，不选择删除用户资料。确认开始菜单/应用文件移除、托盘和进程退出；保留应用数据目录，不手动清理。重新安装同版本核对合成资料的实际保留情况。另一种安装包格式若测试，先完成并记录当前卸载再开始。
- 预期：卸载行为与实际选项一致，不误删其他用户/客户端文件；用户数据是否保留如实记录，不能把卸载等同安全擦除；重装可正常启动。遇到残留/不可卸载记录，不修改注册表绕过。
- 记录：M10，卸载选项、应用列表/重装结果；状态：未执行。
