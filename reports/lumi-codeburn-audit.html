04 · 关键口径与有意保留的差异

核查项Lumi 实现 / 核对结果
未缓存输入与缓存输入统一为 CodeBurn 的 fresh input，缓存读取和写入单独保存；总量 = 输入 + 输出 + 缓存读 + 缓存写。cachedInputTokens 是缓存读取的别名，禁止再次相加。旧版 Codex 的输入含缓存，所以升级后输入数会变小，应结合缓存卡与总量理解。
推理 TokenClaude、Codex、Copilot、DSH 的 output 已包含推理，禁止再加；其他来源依照上游 billableOutputTokens 合并。对全部43个注册项逐项运行边界测试。
累计、流式、恢复及多格式复用上游 Codex 累计差分/恢复/分叉去重，Claude 流式消息去重与 advisor 计数，Copilot store/逐条调用/shutdown 对账，以及 OpenCode 文件与SQLite来源去重。
估算与缺失字段保留上游 isEstimated，界面及CSV有标记。该标记可能仅表示费用估算（如 Amp），不能直接断言 Token 是估算。Lumi 拒绝非有限、负数或非安全整数计数；缺失保持未知，空范围为0。
独立网关Vercel Gateway 使用官方 report API，须已有 AI_GATEWAY_API_KEY 或 VERCEL_OIDC_TOKEN 及服务端权限；本机未配置时不发起请求。其记录是按日/模型聚合，不是真实逐会话或逐小时数据；默认从“全部”中排除，单选网关时查看，防止与本地客户端重复。
历史切换与刷新失败每软件在成功完整读取后事务替换派生记录，防止新旧ID并存重复。失败保留最后有效数据。网关适配比上游额外把HTTP失败转为采集失败，避免误把失败当作零数据覆盖历史。
名称与隐私Codex 仍刷新 session_index + 只读 threads.title；Claude 使用上游 aiTitle。来源没有明确名称则保留脱敏编号，不用对话正文猜测。上游辅助缓存归 Lumi，保存前剔除消息、命令和行为字段；会话摘要与导出只使用显示元数据和计数。
已扫描范围未发现的软件不进入顶部软件 Tab，也不进入下方筛选和统计。零记录软件可保留0展示。分页和CSV以同一筛选范围汇总，展开原始计数按需读取。
