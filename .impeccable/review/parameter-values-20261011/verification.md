# 参数名／参数值与输入框内编辑开关

2026-10-11。用户要求删除名称列，变量改为参数名，默认值改为参数值，编辑开关悬浮在参数值输入框最右侧。

- 表头为序号、参数名、参数值、参数说明、必填，最后是删除图标。移除独立名称与编辑列；已有 Schema title 保留为原数据，参数名更新 key 与绑定 key；参数值仍正确更新公开 default 或私有 value，数据类型、私有遮罩和排序功能保持。
- 参数值内部的开关复用共用 Checkbox，与 Input 同属必要布局组合。绝对定位在右侧，输入文本预留控件空间；没有另写颜色、圆角、阴影、焦点或动效。开关默认开启，延续用户确认的本行锁定语义，关闭后仍能开启恢复；全局只读／忙碌状态一并禁用。
- 表头说明图标解释开关；排序和删除的可读名称使用当前可见参数名。UI组件里的同一参数表预览同步更新。
