# 勾选框独立居中与参数列表背景

2026-10-11。原布局把拖动图标与勾选框整体居中，因此勾选框偏右。现在第一列108px（共用控件高度3倍），勾选框自身与表头共用水平中轴；拖动图标在同一单元格左侧绝对定位，保留36px目标区，两者不重叠，显隐不改变勾选框的位置。

列表使用既有 Card density="flush" 提供背景、边界和8px圆角，外框左边缘与 FieldGroup 的外部参数标题对齐。业务只添加容器最小宽度与定位布局，没有覆盖共用控件外观。既有288px内部滚动、行内图标显隐和排序保持。UI组件参数预览复用同一组合，三份规范同步。

pnpm check 通过：25文件、194测试；类型、Lint、首页契约、Rust fmt/check/clippy通过。前端和macOS调试应用构建通过，git diff --check与布局检测通过，保留既有构建提示。

原生深色1120×820与720×560一轮确认：表头和勾选框水平中心一致，拖动图标显示时位置不变；背景与外部参数标题左对齐，窄窗口容器不外溢，内容仍在内部横向／纵向滚动。应用在保存禁用且无活动任务时重启到新构建，未修改参数或执行工具。验证中用户打开的独立运行窗口保留；通过Window菜单回到主配置窗口继续确认，最终主窗口恢复正常尺寸，保存禁用。示例已保存版本及定义哈希与基线一致。
