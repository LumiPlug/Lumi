# 工具 UI 审查数据

已在当前运行的 Lumi 中通过 `/app/tools` 创建 16 个以「审查 ·」开头的工具，现有工具保留。`created.json` 记录本次工具与执行记录的 ID，`server.json` 记录本机 HTTP/MCP 演示服务端口和进程。文件不保存 Lumi 会话凭据。

- 三种类型均包含草稿、已启用、已停用的示例。
- 执行记录包含成功、失败、超时、已取消和运行中；使用真实的执行、停止与状态转换。
- Shell 成功示例有默认外部参数；失败示例输出 stderr 并退出 2；长日志示例触发截断及输出过大提示。
- Shell 运行中示例每 10 秒打印日志，最长 1 小时，支持在 Lumi 中停止。应用退出也会停止它。
- HTTP 示例使用 `127.0.0.1` 上的演示接口，包含 JSON、Form、嵌套返回字段规则、503 和超时。
- MCP 示例通过真实工具发现获取 echo/status/fail 三个操作，已有成功与失败历史记录。

运行 `node .impeccable/review/tool-state-fixtures/create.mjs --inspect` 可读取当前状态。普通执行可续建尚未创建的示例，已有工具不覆盖，已有任务不重复启动。演示服务独立于 Lumi，以便应用重启后仍可测试；应用重启后历史运行中任务会按产品行为显示已中断，可在界面重新启动。

这些是当前 Lumi 的审查数据，不是产品内置工具或自动播种逻辑。未修改产品 UI、授权规则或原有用户数据。
