# Lumi 桌面界面设计

## Terminal 运行参数左右布局（2026-10-12，当前方案）

运行参数改为逐行左右布局，移除五列表头。左侧显示实际参数名，下面用共用 Badge 展示“外部可见／外部不可见”和“必填／可选”；右侧为共用 Input，参数值仍可编辑。描述只在非空时通过参数名旁的共用 Tooltip 说明图标呈现，悬停、点击或键盘聚焦显示完整描述；气泡跟随现有主题、边界适配和 Escape／滚动关闭规则，不在业务层覆盖视觉。

列表继续复用左对齐 Card 背景、288px 固定高度和内部垂直滚动；正文内不再需要横向浏览五列。每行右侧输入占较多宽度，左侧长参数名和 Tag 可换行；列表内容宽度不足 420px 时输入移至信息下方。参数名用 label 关联本行输入，错误说明保持 aria-describedby 与首个错误聚焦。执行后的配置及详情使用同一左右布局展示只读快照。本次仅调整运行 UI，工具配置页的参数编辑表、真实参数契约、手动覆盖接口、私有值遮罩、工作目录和两个运行节点沿用既有行为。本节替代运行参数五列文本展示方案。

## Terminal 运行配置与工具配置统一（2026-10-11，当前方案）

终端运行窗口的配置节点直接展示工作目录、外部参数表，复用工具编辑页的 TerminalWorkingDirectory 与 TerminalParameterTable 业务组合。工作目录沿用 inline／wide Field、revealEnd Input、选择文件夹和图标说明；留空使用用户主目录。参数表沿用左对齐 Card 背景、外部可见／参数名／参数值／描述／必填五列及 288px 内部纵向滚动，窄窗口在表内横向浏览，外部可见和必填文本与标题水平居中。

本次运行仅编辑目录和参数值；参数名、描述、外部可见、必填直接以文本展示已保存配置；两项布尔状态显示“是／否”，描述换行显示完整内容，不提供增加、排序与删除。所有参数值使用可编辑 Input；数组／对象使用单行 JSON，布尔输入 true／false，枚举填写其已有值，继续通过真实参数 Schema 校验；私有固定参数使用密码输入。校验失败聚焦实际参数值并关联错误说明，通过顶部 Toast 提示。开始运行后，配置展开与详情均以同一表格只读展示冻结的本次输入；调整后再运行保留输入。目录与固定值仍通过既有手动覆盖接口提交，不保存工具定义、不改变 AI 参数契约。HTTP／MCP 继续沿用原有表单。终端“查看技术信息”收进外部参数标题行右侧，取消空的“更多设置”层级；目录在运行节点中取消工具编辑页的额外上下外边距，让两个节点保持紧凑。运行表移除操作列后，最小宽度为两倍共用字段宽度（640px），标准 760px 窗口展示全部五列。提供恢复默认值／固定值及不提供可选参数的既有操作。本节替代终端逐字段纵向表单方案。

## 共用整行拖动状态（2026-10-11，用户确认扩展）

ui/index 导出 useTableDragPreview，供排序组合使用。按住手柄时复制当前行的视觉快照，保留输入框正在编辑的文字、勾选状态及固定值遮罩；浮层不可点击、不可聚焦、不参与表单提交或辅助技术树，移除重复 ID 与校验目标。实际输入控件保持挂载，不因浮层重新创建而丢失草稿。浮层复用主题面板背景、8px 容器圆角与浮层重阴影，并限制在参数表的横向可见区域。

原行保留布局高度，显示共用虚线占位框，内部内容暂时隐藏；浮层跟随指针纵向移动，整行顺序实时更新。自动滚动时浮层仍跟随指针，占位在实际落点；松开后按共用 100ms 按下时长回落，再移除浮层并恢复手柄焦点。Escape、指针取消、失焦或窗口尺寸变化恢复原顺序并清理浮层；卸载立即清理。减少动态效果时直接落位，高对比模式保留系统边界与占位线。键盘排序保持既有方向键与 Home／End 行为，不生成浮层。UI组件中的 Terminal 参数组合展示同一拖动效果。

## 共用滑块开关（2026-10-11，用户确认扩展）

Switch 由 ui/index 导出，接口为 label 与原生 checkbox 属性；使用 checkbox input + role="switch"，保留表单关联、标签点击、Tab／Space 操作、ref、禁用及辅助说明。轨道宽度复用控件高度，轨道高度复用 checkbox 尺寸，圆角沿用 4px 控件规范；滑块位置区分开关状态，开启使用主操作色。颜色、焦点、重阴影、120ms 轻微滑动、减少动态效果和强制颜色支持由共用层维护。UI组件交互控件页面提供真实开启／关闭和两种禁用状态，终端参数必填使用同一组件。业务不单独定义开关视觉。

## Terminal 外部参数表（2026-10-11，当前方案）

表头文字为“外部可见、参数名、参数值、描述、必填”，删除列无可见标题。拖动图标与外部可见勾选框仍在同一单元格水平排列，必填共用 Switch 独立成列且不重复标签，删除 IconButton 位于末列。鼠标悬停或键盘焦点进入参数行，以及正在拖动时，才显示该行的拖动／删除入口；业务通过原生 hidden 状态控制显隐，预留 36px 图标位置，保持输入框布局稳定。未激活行仍可从外部可见及输入框进入，焦点进入后可用 Shift+Tab 访问前方拖动手柄；焦点仍在行内时不隐藏控件。取消序号及参数值内的可编辑开关；全局只读或忙碌时统一禁用。

列表背景复用 Card density="flush"，背景外框与“外部参数”标题左边缘对齐；背景、边界、8px 圆角均由共用组件提供，业务仅安排容器宽度与内容布局。

外部参数列表高度固定为 8 倍共用控件高度（288px），超过高度时只在列表内部纵向滚动；窄窗口保留同一区域的横向滚动，滚动条预留空间。参数数量或输入错误不会撑高列表。列表滚动时重新匹配鼠标所在行，显隐跟随实际指向位置。拖动时优先在此视口的实际可见上下边缘自动滚动，小窗口按外层表单裁剪范围计算触发边缘；浮层横向裁剪避开垂直滚动条。

“外部可见”标题移除说明图标；勾选框本身与标题共用列的水平中轴；拖动图标独立定位于同一单元格左侧预留位置，第一列宽度为3倍控件高度（108px），避免组合占位把勾选框推向右侧。勾选框对应字段 aiVisible。关闭时把当前公开参数值移入内部固定 value 并移除 Schema default；开启时把固定值转为公开默认值，保留原类型。参数名编辑字段 key 和绑定 key，描述编辑 Schema description；既有 Schema title 元数据保留。公开参数值编辑 Schema default，内部固定参数值编辑 value 并使用密码输入框。留空移除公开预设，数字、布尔和 JSON 保留类型。

拖动手柄复用 text Button + GripVertical，按住时整行浮起并显示占位，上下拖动并在松开时落位；靠近内容边缘时自动滚动；键盘方向键或 Home／End 调整顺序，Escape、指针取消或窗口失焦恢复原顺序。行身份、未完成输入、可见状态、参数值及必填状态随整行移动。操作只修改草稿，保存后才写入工具。删除复用 IconButton + Trash2，焦点移至相邻行，删除最后一行后回到添加按钮；HTTP 参数配置保持既有行为。

结构使用语义表格，控件复用 FieldGroup、FieldTitle、Card、Input、Checkbox、Switch、Button、IconButton；业务 CSS 只安排列宽、间距和拖动光标。表头与参数行使用同一共用滚动视口，窄窗口可横向浏览；保持 36px 控件高度、现有重阴影、主题与键盘焦点。UI组件中的 Terminal 参数预览复用同一组合，自动展示最新布局和交互。本节替代此前含名称、序号和本地编辑锁定的布局。

## 配置与执行节点（2026-10-11，当前方案）

2026-10-11 紧凑布局修订：移除运行窗口及运行弹窗标题右侧的 ×，独立窗口通过原生窗口控制关闭，内嵌弹窗保留 Escape 和原有关闭保护。两节点间距为 12px，节点正文距标题 4px，取消 28px 左侧缩进，配置字段与执行内容共用窗口正文的左右边界。参数复用 Field 的 inline／wide 布局，标签与控件同行；窄窗口按共用组件规则回到上下排列。节点控件保持共用组件的 36px 最小高度、字号、状态和焦点效果；只调整业务布局。

用户要求独立运行窗口从上到下始终显示“配置”和“执行”两个节点，复用 StageSection。准备时配置展开、执行待开始；提交后配置默认折叠，可展开查看本次只读输入，执行节点展示真实状态、输出和结果；结束后执行保持展开。历史任务的配置节点展开时明确说明缺少输入快照。重新运行先回到配置，保留当前输入。

字段说明通过 Field hint 复用说明图标，支持悬停、点击和键盘焦点查看，不另占正文。删除工具用途重复文案、准备就绪／检查参数数量／无需输入说明和运行中的关闭方式说明；保留校验、不可运行原因、断连与结果未知等必要反馈。标题不重复显示节点已呈现的运行状态。配置折叠时执行区填满剩余高度；展开时正文可整体滚动，执行区保持有界可读高度，不压缩为零，底栏固定。终端详情与复制放在输出顶栏。终端执行方式选择继续移除，原生标题栏继续与内容同背景。本节替代下方单页配置及说明直接显示的方案。

## 普通用户工具运行（2026-10-11，当前方案）

运行窗口默认是填写内容与开始运行的单页表单，展示工具用途、不展示执行器类型标签；Terminal 不选择一次执行／持续执行，使用既有 run 操作或工具唯一操作。技术与连接内容折叠至更多设置，完整配置通过技术信息弹窗查看。字段从上到下排列，名称优先使用 Schema title，说明直接显示；数值使用输入框，布尔值使用是／否。无输入时提示可直接运行。

终端直接显示运行内容并省略行号，HTTP/MCP 保留结果与运行记录切换；结果复用 DocumentViewer 阅读排版，复制入口与 Tab 同行。查看详情打开只读输入、原始数据与技术信息入口，历史缺失快照明确提示；退出码与 HTTP 状态收进详情。不可重放的历史任务只提供调整后再运行。所有交互均组合既有共用组件，无新增页面皮肤；标题栏与正文同背景、固定操作栏、真实停止、日志暂停跟随、顶部 Toast 继续保留。本节取代下文较早的准备 Tab 与本次参数 Tab 方案。

## 工具运行窗口（2026-10-11）

用户确认固定标题和底栏、准备聚焦输入、执行后聚焦输出的独立窗口方案。移除配置／运行阶段节点，参数查看使用窗口内 Tab；Terminal 显示日志，HTTP/MCP 用日志／结果 Tab 共用主要内容空间。成功默认结果、失败默认日志，主动切换保留用户阅读上下文。输出随窗口伸缩；阅读旧日志暂停跟随，回到最新恢复。重新运行文案为“修改并重跑”，保留输入并回到编辑，再点击运行才执行。目标只读，已有请求头和正文值保留编辑能力；历史任务不以当前配置冒充原参数。

macOS 运行窗口采用 Overlay 和隐藏系统标题，内容延伸到标题栏，标题栏安全区、窗口标题、正文、底栏均使用同一 panel 背景；原生控制和拖动区域保持可用。WindowPanel fill 正文布局、原生标题安全区与 LogViewer fill／跟随恢复先在共用组件和 UI组件预览实现。控件、重阴影、字号、动效、主题、顶部 Toast 与关闭确认沿用既有规范。本文下方 2026-10-07 的固定高度／双区域描述为历史行为，由本节替代。

## 知识库（2026-10-06）

2026-10-10：知识目录默认只展开第一级目录（根目录），显示其直属文档与子目录；第二级及更深目录初始折叠，用户可手动展开、收起。切换知识库或发布版本恢复默认展开状态，同版本切换阅读文档保留展开状态。桌面目录与窄窗口目录浮层复用同一 TreeView 默认规则，设置中的 UI组件预览同步展示三级目录。

Skills 下方增加知识库图标入口。内容首屏为项目卡片网格，名称18px、两行介绍14px、文档/节点/更新日期12px；名称紧随图标位于同一行，状态标识位于该行右侧。文档与节点数量在卡片左下方，更新日期在右下方，按本地日期显示为 `YYYY-MM-DD`（例如 `2026-10-06`）。长名称允许换行；日期保持完整，窄卡片必要时换至下一行并右对齐。只突出待授权、构建异常等必要状态，不加营销区域或重复页面标题。

详情采用生成知识目录与内容双栏，默认右侧项目图谱。项目名称单独位于顶部第一行，下一行按“XX 文档、XX 节点、一句话介绍”的顺序呈现，统一复用现有元数据文字样式，不再重复显示来源目录别名；空间不足时介绍自然换行。未选中节点时只显示图谱，不再显示下方或侧边的“项目全景”介绍区块，也不保留空检查栏；选中节点后保留节点详情、关系及来源操作。文档切换与检索结果通过显隐保留图谱实例、视图模式、选中节点与相机状态，清空检索返回原阅读上下文。切换知识库、版本或邻域允许重新布局。图谱有关系清单替代视图、明确推断标记和证据入口。关系清单完整呈现本次图谱返回的节点与关系，不受紧凑图谱节点数限制，Core 的图谱返回限额仍适用。

图谱默认占满目录右侧的可用内容区，初始化和窗口尺寸变化时适应画布并居中；不以固定高度留下空白。节点类型图例竖排悬浮于画布右下角，不占用单独的底栏，也不阻挡图谱拖动。关系清单不显示图例。

节点悬停或点击选中时，点亮该节点及直接关联节点，弱化其他节点与关系；关联线以朝关系箭头方向的流动虚线显示，长划线与短划线分别保留原文/解析及推断关系区别。移开鼠标恢复选中节点的邻域，未选中则恢复全图。流动仅用于聚焦关系，不作为常驻装饰；减少动态效果、后台或图谱不可见时停止流动，保留静态关联高亮。键盘通过关系清单选择节点后可返回图谱查看同样的邻域高亮。

关联线以 10 CSS 像素/秒的屏幕速度流动，缩放后保持同样速度；不再用短虚线的循环周期作为速度指标。切换聚焦节点保留动画相位，卡顿或后台恢复不发生大幅跳变。线条与箭头使用关系起点节点的颜色，聚焦时提高可见度但不改变该颜色。

响应式判断采用内容容器宽度：不超过 760px 时目录进入 Modal，不超过 1050px 时图谱检查区转至下方，仅选中节点后的图谱采用 420px 高度以便阅读下方详情。Canvas 自身宽度小于 720px 时最多显示 6 个可读标签节点，优先项目与模块并保留选中节点，以紧凑网格和曲线关系减少标签遮挡；图例显示已展示数量。内容自行滚动，不遮挡固定搜索与导航。历史版本固定读取，发现新发布版本以切换按钮呈现，不静默替换正文。

自 2026-10-07 起按项目标识＋分支分组，无 Git 默认为 main。卡片增加独立分支元信息行，状态和版本属于该分组；详情通过共用 Select 切换同项目分支，版本 SHA 随选择的知识历史版本显示。新建表单复用 Input、Checkbox、Field，只填写项目名称、标识、介绍和 Git/分支，不选择或授权目录。移除授权、撤销、重新授权、来源扫描、检查变化和部分来源发布。外部 AI 自行取得 Git 元信息并提交知识；Lumi 只存储与读取，不展示未经核实的“当前项目已最新”。引用弹层显示相对路径、行号、分支、版本、SHA 和文件哈希，不展示原文。导入只接受 v3。接管、停止构建、历史恢复说明影响并确认；操作结果仍使用顶部 Toast。

本规范于 **2026-09-29 经用户确认**，是现有页面统一和后续功能开发的 UI 实施依据。品牌原文 `DESIGN.md` 保留不改；其历史组件参数与下方已确认规范不一致时，以本规范为准。

界面直接实现在应用中，开发入口为 `/`。仅开发环境在设置中提供“UI组件”验证页，预览页直接调用业务共用组件；正式构建移除入口及预览页面代码。组件目录与使用约定见 [共用 UI 组件](./UI_COMPONENTS.md)。

## 视觉定位

2026-10-07 终端运行窗口：Terminal 不显示独立结果区，日志区复用共用 LogViewer 的 combined 尺寸，合并原 240px 日志与 200px 结果高度为 440px。保持内滚动、行号、复制日志和自动置底；退出码及错误在终态日志末尾显示，阶段标记保留停止／失败／完成状态。HTTP/MCP 仍使用双区域。终端无自动运行超时，停止按钮在后端确认退出前显示“正在停止…”。

以用户提供的 [Obsidian & Solar Amber 设计说明](./DESIGN.md) 为项目配色基础，使用黑曜石分层背景、锌白文字、太阳琥珀强调色。保留用户 Logo 的 L 与星芒原始路径和渐变。界面内采用去掉底板、边框、环境光与光晕滤镜的透明 SVG，应用图标使用独立的渐变底板版本。

采用简约桌面工具布局：无独立底板的图标侧栏，以及铺满右侧区域的内容面板。左侧与窗口普通背景融合，去掉侧栏边界线；右侧以完整面板的表面色阶突出视觉层级。应用移除右侧顶部重复的 Lumi 名称与顶栏，面板与窗口顶部、右侧和底部贴合，不保留外边距、圆角或悬浮阴影。macOS 窗口隐藏系统标题，以 Overlay 样式让内容延伸到标题栏区域，保留原生窗口控制按钮及顶部拖动区域，并给内部控件留出安全间距。面板内部保留阅读和操作所需的留白，内容在面板内部滚动。

内容面板与侧栏布局统一维护在 `src/styles.css`。实际应用沿用真实 Core 数据和已有能力草稿流程。左侧不显示 Core 状态点或连接状态文字，服务状态只在设置中查看。主题切换只出现在设置的外观区域；实际应用保存外观偏好。

左侧菜单切换后，右侧不重复显示菜单名称的大标题。工具、Skills、设置及已有工作台保留页面说明、区块标题和操作；页面名称仍以辅助技术可读取的标题提供。首次配置工作台的引导标题和步骤标题用于说明当前流程，继续显示。

按用户调整，深色窗口与侧栏使用 Surface Tier 1，右侧面板使用 Canvas Base；浅色窗口使用暖灰色，右侧面板使用白色。

## 应用与系统图标

应用显示名称统一为 `Lumi`。Tauri 的 `productName` 与 `mainBinaryName` 均设置为 `Lumi`，macOS `Info.plist` 明确设置 `CFBundleDisplayName`，使应用包、主程序与系统显示名称一致。调整名称后需重新构建并启动新的 `Lumi.app`，旧构建产物不会随源配置自动更新。

`src/assets/lumi-logo-transparent.svg` 为唯一 Logo 源。`pnpm generate:icon` 从该文件生成 Tauri 的 PNG、ICNS、ICO 及桌面所需尺寸，以及界面专用的无光晕 `src/assets/lumi-mark.svg`。应用图标使用 512×512 方形画布、448×448 黑色渐变圆角底板，琥珀标志居中，原始路径放大 1.12 倍，主体高度约 282px，四周保留留白。系统状态栏使用同一 L 与星芒形状的纯白透明图标，移除渐变与发光滤镜以保持小尺寸边缘清晰；关闭 macOS 模板着色，保留纯白设计。开发与打包共用同一组桌面图标。生成脚本仅保留打包配置引用的桌面图标及托盘 PNG，不保存移动端图标或中间 SVG。

避免大面积渐变、装饰图表和统计卡片。深色为品牌基准，浅色为补充对照方案，原始设计说明未规定浅色值。

ui-ux-pro-max 检索的 Minimalism & Swiss Style 适用于本项目；检索中的营销页结构与通用青绿色方案不适用。用户设计说明优先于检索建议。

## 已确认的动效

| 场景                   | 时长与变量                       | 行为                                       |
| ---------------------- | -------------------------------- | ------------------------------------------ |
| 悬停、选中             | 120ms，`--lumi-motion-hover`     | 背景、文字与边框变化，布局不移动           |

浮层进入采用 `--lumi-ease-out: cubic-bezier(.16, 1, .3, 1)`，退出采用 `--lumi-ease-in: cubic-bezier(.7, 0, .84, 0)`。动效用于解释状态变化，不能延迟业务执行。连续操作可替换或打断当前反馈；不使用装饰性循环、滚动劫持或大面积渐变。

尊重 `prefers-reduced-motion`：取消位移、缩放、旋转和过渡，直接展示可读的最终状态；操作、计时和辅助技术播报保持可用。菜单与确认弹窗只在相应功能实际需要时引入，不为展示动效新增操作流程。

## 交互

### 工具配置与运行

AI 调用与用户手动运行同等重要，共用工具定义、公开参数、整体授权与 Registry。点击卡片进入子页面的“基本配置”；卡片的运行按钮进入子页面并打开参数弹窗，审阅按钮进入配置并打开独立授权确认弹窗。子页面提供“基本配置”“工具配置”“运行记录”三个 Tab：名称与用途、类型连接与参数、真实任务历史分别呈现。两个配置 Tab 切换保留编辑内容，进入运行记录沿用未保存保护；校验失败切换至错误字段所在 Tab 并聚焦。列表与详情的选中样式复用共用 Tabs / Segmented 的琥珀文字、强调底色和边框。卡片运行和设置齿轮始终保持 outline，悬停、键盘聚焦和按下时以图标底部同色模糊阴影反馈，复用 `--lumi-icon-glow-blur`。返回列表保留筛选及滚动位置。

新增采用两步引导，标题下显示当前步骤。第一步依次填写名称、选择 TERMINAL／HTTP／MCP、填写可选用途说明；名称支持中文，点击“下一步”校验名称后进入类型配置。第二步提供“上一步”和保存草稿，保存时自动校验配置。返回与切换类型保留名称、用途及各类型已经填写的有效配置，不因切换清空用户输入。

Terminal 配置可选工作目录，支持手动输入或原生文件夹选择，留空使用用户主目录；Shell 默认由系统识别。外部参数逐项填写变量名、默认值和输入说明，多行 Shell 命令采用有标签的等宽编辑区且必须填写。运行时参数通过环境变量传入命令；默认值与说明属于 AI 公开参数，不填写凭据。新增与编辑均使用这一命令表单。

HTTP 配置请求方式、地址和请求头，默认 GET；参数格式可选 Query、Form 或 Body（JSON），参数逐项编辑，JSON Body 支持嵌套对象。GET／DELETE 使用 Query 参数。允许返回字段使用与响应 JSON 相同拓扑的结构化规则：叶值为有效正则，数组用一个元素描述每项，匹配时保留原值，不匹配时移除；配置后只保留已声明且匹配的字段，未配置或空规则对象沿用原输出规则。

MCP 配置 HTTP 服务地址及 Header，或 stdio 启动程序及每行一个的参数。可选“工具名”精确匹配上游名称，留空读取全部操作；“读取工具”真实连接服务或启动程序，自动获得操作和参数，读取不会授权执行。修改连接信息或工具名后提示重新读取。

公开命名空间自动生成，三类工具的必要连接信息、参数与返回规则直接在当前引导表单中填写。高级设置和旧配置编辑器已删除，不再提供命名空间、完整操作 Schema 或 AI 可见预览的单独编辑区域。

完整配置通过 Core 读取和保存；版本冲突保留输入。未归档配置默认可编辑，右上角直接显示“保存”，不提供“编辑”“取消编辑”和“禁用”按钮；已归档工具只读。保存后继续可编辑，未修改和运行记录 Tab 中保存按钮禁用。返回或离开页面遇到未保存修改时，先通过独立确认弹窗提供继续编辑／放弃修改。新增弹窗关闭和 Escape 同样保护未保存输入。固定 Header 值默认遮蔽，可由用户显式显示。JSON 错误标记对应字段，保存校验聚焦首个错误，操作反馈复用顶部 Toast。

弹窗由原生 dialog 约束键盘焦点，打开时聚焦标题，关闭后恢复触发控件焦点；关闭按钮保留可读名称和 36px 点击区域。默认宽高复用共享表单变量，桌面内边距 24px，780px 及以下改为 16px；窄窗口弹窗四周保留可用空间，标题和关闭不随表单内容滚出。内容滚动区使用上方 16px、左右 12px、下方 8px 内边距，为浮动滚动条及输入控件的 贴合控件边框的 2px 焦点描边保留空间，避免两侧裁剪或遮挡。Shell 编辑区直接复用共享 Textarea 的焦点描边与光晕。新增流程的取消、上一步、检查与下一步／保存组成独立底部操作区，置于内容滚动容器之外，不覆盖最后一个输入；保存与下一步按钮关联同一配置表单，避免滚动时留下粘性绘制残影。进入沿用 180ms 浮层动效，淡入与最多 4px 纵向位移，减少动态效果时直接展示。弹窗中的反馈通过共享 Toast 视口置于顶层，仍保持窗口顶部位置和计时规则。

工具页继续复用共享字体、圆角、控件高度、语义配色和动效变量；技术配置与日志使用共享等宽字体，卡片名称采用正文层级，弹窗标题采用区块标题层级。卡片悬停、弹窗详情导航和授权审阅使用主题琥珀强调与表面分层，表单弹窗尺寸纳入共享变量，不另建页面视觉系统。

### 操作反馈

按钮操作的成功、失败、校验和提醒信息统一使用全局顶部气泡：在窗口顶部居中，从上方向下进入，避开窗口控制与拖动区域。复用 `src/components/ToastProvider.tsx` 的 `useToast`，原生详情弹窗通过共享 Toast 视口将同一气泡置于弹窗顶层，保持窗口顶部位置与原有计时行为，不再在按钮下方重复显示结果。工作台复制连接提示、复制构建提示词、检查连接，以及设置页 MCP 复制与自检、工具草稿保存均遵循此规则。

气泡使用当前主题表面色与文字色，图标和文案共同表达状态，不抢夺焦点，不阻挡其余区域的操作。普通结果显示 4 秒，错误显示 8 秒；支持手动关闭，悬停或键盘聚焦时暂停消失，重复操作更新内容并重新计时，切换导航不会丢失尚未结束的反馈。屏幕阅读器通过礼貌播报获知结果；减少动态效果时直接显示。按钮加载状态、静态说明及持续的服务状态留在原位置；导航、筛选和模板选择通过控件本身呈现状态。

### 表单与控件状态

字段使用始终可见的标签，占位文字只提供示例。提交校验失败时，顶部错误气泡说明问题与下一步；首个错误字段获得焦点并显示红色边框，设置 `aria-invalid`，通过 `aria-describedby` 提供可读错误描述。输入修正后清除字段错误标记，保留用户内容。服务或网络故障不应错误标记为字段校验问题。

按钮具有默认、悬停、按下、焦点、禁用和加载状态；同一操作区突出一个主操作。加载使用“保存中…”等明确文案，保持控件宽度，防止重复提交。筛选、主题和模板选中状态由控件自身表达，导航切换不额外提示成功。工作台快捷模板点击后直接复制对应提示词，再次点击重复复制并保留当前模板。

工具详情按当前阶段确定主操作：有未保存修改时突出“保存”；无修改且未启用时突出“启用”；无修改且已启用时突出“运行”；已归档时不突出这三个操作。忙碌或服务断连只改变可用状态，不改变当前阶段的按钮视觉层级。

### 可用性与边界

键盘焦点为 2px 琥珀描边；按钮支持 Enter / Space，菜单与弹窗支持 Escape 并恢复触发点焦点。图标按钮具有可读名称，装饰图标隐藏于辅助技术。正文对比度至少 4.5:1，大字及关键图形至少 3:1；常规点击区域至少 36×36px。

加载保留布局，空状态说明下一步，失败提供恢复方式。长名称可换行或截断，但完整文本仍可获取；窄窗口让控件自然换行，不产生整页横向滚动。删除等需要决策的操作使用必要确认或撤销，不以普通结果气泡替代决策。持久服务状态保留在设置等对应内容区域。

工作台与知识库读取真实 Core 生命周期状态：首次状态读取及启动／重启期间显示等待；断连或停止时说明服务未连接，启动失败时说明失败，均提供共用按钮前往设置查看服务；Core 已就绪但工作台连接配置缺失时明确说明配置不可用。知识库列表读取失败时保留重新加载入口。非启动状态不持续显示“正在连接”。

### 工作台初始化

初始化工作台采用无外层卡片的窄幅单列布局，标题、进度、操作统一左对齐。第一步通过紧凑的连接提示行提供复制操作，完整提示词默认折叠，可通过“查看连接提示”展开；复制失败时自动展开并选中供手动复制。底部提供“开始使用”，点击后进行真实 MCP 自检，并确认本次 Core 会话已有外部客户端成功读取工具目录或调用工具；内部自检不计入外部访问。无状态 MCP 的访问记录不能代表客户端持续在线。第二步提供带简短用途说明的“工作助手”“功能入口”快捷模板，默认不选中。点击模板立即复制对应的构建提示词，并显示顶部操作气泡；提示词不包含连接配置。再次点击已选模板会重复复制，切换模板会复制新模板的提示词。下方通过默认折叠的“查看构建提示词”查看内容；复制失败时展开并选中，供手动复制。底部仅保留右对齐的“完成”，无论是否选择模板都可结束引导；不再展示底部宣传说明。完成会保存引导结束状态，展示可重新进入配置的空白工作台，不表示 AI 已创建工作台。连接令牌仅保留在内存中。外部 AI 可以通过 MCP 读取与更新主页文档；提示词明确要求读取当前版本、调用更新工具，并只在保存成功后报告已应用。

连接页的折叠查看入口之后直接展示“开始使用”按钮。

切换导航保留当前引导步骤和模板选择；重开应用保留模板偏好和引导结束状态，恢复配置会清除结束标记。同一已验证会话内恢复配置可返回模板页；重开应用或本地服务、会话发生变化时需重新检查连接。持久化偏好仅含模板类型和引导结束标记（兼容历史延期状态），不保存会话凭证或连接验证结果。

### 设置页水平布局（2026-10-05）

设置页面沿用共享内容宽度，按外观、MCP 连接、首页搭建提示词、Core 四行排列；左侧共享 16px 紧凑区块标题，右侧选项／操作／值靠右，行间细分隔线，不使用窄卡片。外观的深浅主题示意图并排，文字位于图内右上角，选中以琥珀描边和勾选图标表示，取消“已选择”文字；切换即时应用并保存偏好。示意图颜色复用主题映射，键盘焦点与选择态分别保留。

MCP 默认行提供“复制配置”和具有可读名称的详情图标按钮，正常时不重复显示地址、认证与 JSON。详情弹窗展示真实当前会话配置、传输选择及自检，stdio 不可用时说明并禁用；主行始终复制 HTTP 配置。配置缺失或服务未就绪时显示持续说明并禁用复制／自检。复制失败打开详情并选中实际配置供手动复制；会话变动后使用当前配置，不持久保存连接令牌。

首页搭建提示词行提供“工作助手／功能入口”选择和复制按钮，复用 `buildWorkbenchPrompt` 与首页模板偏好，不包含 MCP 会话凭据。点击复制同时打开独立只读预览，支持再次复制、关闭与 Escape；失败聚焦并选中文本。提示词无需 Core 就绪即可查看复制。预览不增加保存、确认或执行动作。

Core 只保留真实状态与版本，值区域最右对齐，移除重复标签及“本地数据目录：可用／不可用”。状态同时用文字表达，版本未知时明确显示；辅助技术继续获得状态和版本标签。

720×560 下保持水平行，进一步变窄时允许控件换行或移到标题下方，维持字号与 36px 操作高度，不产生横向整页滚动。详情与提示词弹窗共享模态结构，标题和底部操作保留，正文独立滚动，焦点限制在弹窗中并在关闭后回到触发控件；结果继续通过顶部 Toast 展示。

### MCP 连接配置

设置页的 MCP 水平设置行默认复制当前会话的 HTTP 配置，独立详情弹窗支持 Streamable HTTP／stdio 代理配置切换、查看与复制，以及实际 MCP 握手和工具发现自检。配置由主窗口专用 Tauri IPC 从 Core Supervisor 读取，与 Core 使用同一会话端口和令牌；HTTP、stdio 和应用内部 API 共用这个令牌。Lumi 重新启动后需要重新复制配置。本地服务状态来自 Core Supervisor；检查连接使用真实 MCP 握手。浏览器开发环境没有桌面 IPC 时提示从桌面应用获取配置，不生成虚构凭证。

桌面复制由主窗口专用命令验证凭证后，使用 [Tauri 官方系统剪贴板插件](https://v2.tauri.app/plugin/clipboard/) 写入文本；主页 iframe 不获得直接剪贴板权限。浏览器开发环境使用浏览器剪贴板 API，保留选中并手动复制的失败反馈。

### AI 开发的主页

官方静态 HTML 模板和开发知识库严格匹配 Lumi 版本。根目录 `index.html`、`app.js`、`style.css` 是必要文件，其他框架可输出相同静态结构；用户无需 Node 或构建。空主页沿用连接与开发引导，提示词要求其他 AI 通过 MCP 获取官方工程和现有源码。已有主页直接展示内容，宿主顶部不重复显示主页名称或“让 AI 调整”按钮；页面名称仍供辅助技术识别。工作台不显示开发资料、导入、导出或历史版本操作；模板、知识库、主页发布、工程导出和历史版本操作由 MCP 工具提供给 AI。页面在隔离 iframe 中加载，内部布局由 AI 开发；模板提供共享主题、字号、圆角、焦点与减少动态效果支持，按钮反馈经 SDK 转到宿主顶部气泡。宿主加载/契约不匹配/断连状态显示在原位置，失败提供重试入口；需要历史恢复时引导 AI 使用 MCP。主页活动时每 2 秒检查版本，版本变化重新加载；源码和历史保留。

首页首次等待本地服务或工程读取，以及 iframe 桥接尚未建立时，在内容中央显示主题琥珀色 Lumi 文字，使用共享页面字号与 `--lumi-loading-breathe`。文字仅以透明度从 0.35 到 1 呼吸，不位移、不缩放；加载期间提供“正在加载 Lumi”的辅助技术状态，桥接就绪后立即移除。减少动态效果时显示静态文字。启动、重启或断开阶段每 250ms 查询本地服务状态，正常状态恢复每 2 秒查询；首页版本检查继续每 2 秒进行，已加载工程保留 iframe，同版本读取不重载。加载或桥接失败显示恢复入口，已有内容在同步失败时保留。

导航切换后，键盘焦点交给对应界面的标题。协议不匹配时提示导入当前版本的 HTML 主页；仅可加载、导出和恢复符合当前契约的工程。

## Skills 页面（GPT-6-Astra 设计，2026-09-30）

Skills 内容随窗口铺满可用宽度，不受通用阅读区最大宽度约束；使用三列网格卡片，窄窗口降为两列或一列，列表高度随窗口调整。卡片内边距为 8px、首行 36px，归档／恢复按钮保留 36px 点击区域。卡片首行依次为 12px 来源标签、占据剩余宽度的 14px 技能标题及 36px 归档／恢复图标按钮；下方保留两行 13px 描述。长标题截断，卡片悬停边框使用主色。点击卡片或按 Enter / Space 进入文件详情二级页面：左侧为可展开的目录及文件选择，右侧为选中文件的内容，默认打开技能主文件；目录和文件内容独立滚动。页面铺满内容区；左侧使用 `--lumi-file-tree-width`（240px），窄窗口不超过内容宽度的 32%。Markdown 支持标题、列表、引用、代码块、GFM 表格和任务列表，YAML 元信息可展开查看；其他 UTF-8 文本显示源码，PNG/JPEG/GIF/WebP 可预览。相对文档链接切换技能目录内文件，本地图片按可见范围读取；外部网页链接由用户点击后在浏览器打开，外部图片不自动加载。来源、描述和归档状态收纳在左侧“来源与状态”，顶部提供选中文件的“复制路径”；返回按钮恢复列表滚动与卡片焦点。初始焦点落在标题，键盘导航保留主色焦点提示。复用共享圆角、字号及动效，不产生横向溢出。

来源标签使用平台专属背景与文字色：Codex 紫色、Claude Code／Anthropic 暖橘色、Qoder 蓝色、QoderWork 玫瑰色、Cursor 灰绿色、Gemini CLI 沙金色、OpenAI 灰青色；未知来源沿用中性色。颜色只辅助区分，保留平台名称；共享色值在 `src/theme/palette.css` 分别定义深浅主题，与服务状态语义色分开。

技能列表默认按真实 `SKILL.md` 文件的创建时间倒序（较新在前），来源筛选、搜索与已归档沿用该顺序。创建时间来自文件系统 birthtime，仅近似表示添加到电脑的时间，不承诺真实安装日期；不使用文件修改时间。无效日期、非正时间及已确认的 Unix 纪元首秒（0–1000ms）占位值均视为未知；显示与排序共用同一标准化规则，缓存读取时立即生效。无法获取有效创建时间时回退到 Lumi 首次收录时间，两者都未知的记录置后；排序时间相同或都未知时按名称、真实路径、ID 稳定排序。每次成功扫描更新文件创建时间并为历史记录补充该值；内容修改和归档／恢复不改变排序时间，文件重建或重新安装后按新文件的创建时间排序。文件缺失或读取失败时保留缓存日期；Lumi 首次收录时间仍保持原值。

### 组件复用规则（2026-10-05）

首页工作台以外，全部新增或修改 UI、视觉与交互必须复用共用组件，与 UI组件预览保持一致；页面仅提供内容、状态、回调与布局，不另定义控件外观。现有组件或状态不足时必须先向用户说明并确认，确认前不得自行新增视觉组件、效果或临时替代样式。确认后先完成组件及预览，再应用业务并同步规范。工具与技能详情采用整页二级布局；工具新增／运行、知识搜索、设置预览及二次确认统一复用 Modal；业务编辑器的未保存判断仍由业务回调决定，取消离开后保持可编辑。组件用法与执行检查见 [共用 UI 组件](./UI_COMPONENTS.md#业务采用与强制规则)。

共用控件的焦点描边使用共享 `--lumi-focus-outline-offset: -2px`，叠于边框内侧，避免选中与焦点叠加变粗。按钮、Tab、选择卡片等鼠标点击仅显示选中／悬停效果；键盘导航保留可见焦点，选中且聚焦时用既有光晕区分。输入框保留鼠标聚焦后的编辑反馈，关闭弹窗仍恢复真实焦点；强制颜色模式使用同宽虚线替代光晕。

历史记录（阶段式方案前）工具运行弹窗复核：共用 Modal 固定标题／底栏、760px 宽度、24px 内距（窄窗 16px）；三种状态共用标题与基线，运行中保持高度，结束后的短结果自然收紧。准备的主操作为运行，运行中停止为危险操作，结束后关闭为主操作；再次运行为次要操作。参数预览短值紧凑排列，结构化／多行内容使用原有代码样式；结果支持复制，执行过程按成功／失败状态收起或展开。详见工具内容页规范。
