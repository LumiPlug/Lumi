## 4项未验证

- **APP-08**：失焦、关闭、最小化后的服务及恢复已测；最终325秒无窗口观测后重开，原iframe与临时结果仍在，未取得五分钟销毁重建的有效证据，保留疑点。
- **SK-01**：多源同物理目录归并、同名不同目录、搜索筛选已测；特殊文件时间戳回退及排序边界未注入。
- **HOME-09**：未授权调用和离开工作台后的拒绝已测；未取得被替换旧iframe独立持续调用的有效观察证据。
- **KB-16**：writing重启续建、validating时终止Core后的恢复、并发发布和取消竞态已测；归档/接管与Worker完成的精确竞态未强制复现。

## 功能缺口与解释

- **MCP安装Skills尚未实现**。原生导入、托管持久化及MCP搜索/说明/附件读取通过；拒绝安装调用不代表安装能力交付。
- **Memory尚未实现**，真实上下文返回 `features.memory=false`。
- 工作台公开SDK没有直接管理Skills或读取知识库的方法，知识展示旅程通过明确公开投影及已审阅的只读工具完成。
- 3个故意始终失败的fixture操作在两条通道均验证预期错误。完整报表中的6条“无正向成功”提示对应这些负向控制，不是6个遗漏的产品工具。
