# Lumi 0.1.4 预览版

发布日期：2026-10-19。继续使用 GitHub preview 渠道，具体 tag 由 Desktop Build 的运行序号生成。

- Qoder 新增 `~/.qoder/projects/**/*.jsonl` 本地采集，保留旧 IDE SQLite 与独立 QoderWork 来源。输入、输出、缓存读取和缓存创建分别统计；Credits 不换算 Token 或费用。
- 混合格式按显式会话和稳定请求身份核对，保留未匹配历史；无法关联时提示可能重复，不再按整会话排除 SQLite 历史。
- macOS 关闭主窗口后继续后台运行；所有应用窗口隐藏时隐藏 Dock，其他运行窗口仍可见或最小化时保留 Dock。托盘重开恢复窗口、Dock、取消最小化及聚焦。
- 托盘按组提供打开 Lumi、AI 用量、Skills、项目知识、Core 状态与启停、设置、退出。导航保留未保存修改保护，并支持隐藏 WebView 释放后的请求交付。
- Core 停止需确认，仅控制当前应用持有的子进程，经过宿主授权与现有任务/连接清理流程；手动停止不自动重启，失败或超时不冒充停止，不启动第二个进程。Quit/Cmd+Q 与关闭窗口分开。
- 同步应用、Core、共享包、stdio 代理、主页 SDK 与内置模板版本；主页格式和桥接协议保持兼容。

已知限制与验收范围：

- Qoder 国际独立桌面版 0.4.8 的字段结构由用户确认；公司机新对话是否实时写入该路径、实际来源覆盖及计数仍待验收，不承诺所有地区或客户端版本可用。
- 两种格式的请求身份不能完全关联时，统计可能包含重复；界面会提示并保留历史。没有身份来源证据的旧账本不进行猜测匹配。详情见 [来源说明](../AI_USAGE_SOURCES.md)。
- 原生托盘、Dock、多窗口、Cmd+Q、未保存守卫和真实确认弹窗仍待 macOS 实机验收：当前验证电脑锁屏，未以自动化测试代替原生验收。Windows/Linux 未进行完整交互验收；本次发行包仅提供 macOS ARM64/Intel 与 Windows x64。
- 本地完整检查通过400项自动化测试，并完成隔离的请求交付、受管 Core 清理/重新启动与生命周期策略测试；这些结果不代表公司机或原生界面已验收。
- 当前界面语言为中文；未新增通用语言切换体系或自启动设置。停止未能确认时会保留风险状态并禁止重复启动，需核查状态或退出应用。
- macOS 沿用 ad-hoc 签名，未公证；Windows 未配置发布者签名；自动更新未配置。请使用本次预览资产验证，保留已知限制。
