# Lumi 桌面界面设计

本轮产物为独立可交互效果页 `/design.html`。示例资源只存在于页面内存中，页面明确标注设计预览。

## 视觉定位

以用户提供的 [Obsidian & Solar Amber 设计说明](./DESIGN.md) 为项目配色基础，使用黑曜石分层背景、锌白文字、太阳琥珀强调色。保留用户 Logo 的 L 与星芒原始路径和渐变。界面内采用去掉底板、边框、环境光与光晕滤镜的透明 SVG，应用图标使用独立的渐变底板版本。

采用简约桌面工具布局：无独立底板的图标侧栏，以及铺满右侧区域的内容面板。左侧与窗口普通背景融合，去掉侧栏边界线；右侧以完整面板的表面色阶突出视觉层级。实际软件与效果页均移除右侧顶部重复的 Lumi 名称与顶栏，面板与窗口顶部、右侧和底部贴合，不保留外边距、圆角或悬浮阴影。macOS 窗口隐藏系统标题，以 Overlay 样式让内容延伸到标题栏区域，保留原生窗口控制按钮及顶部拖动区域，并给内部控件留出安全间距。面板内部保留阅读和操作所需的留白，内容在面板内部滚动。效果页的设计预览标识移到页面标题旁，搜索入口移到左侧。

效果页和实际桌面界面共用内容面板与侧栏样式。实际应用沿用真实 Core 数据和已有能力草稿流程。左侧不显示 Core 状态点或连接状态文字，服务状态只在设置中查看。主题切换只出现在设置的外观区域；实际应用保存外观偏好。

按用户调整，深色窗口与侧栏使用 Surface Tier 1，右侧面板使用 Canvas Base；浅色窗口使用暖灰色，右侧面板使用白色。

## 应用与系统图标

`src/assets/lumi-logo-transparent.svg` 为唯一 Logo 源。`pnpm generate:icon` 从该文件生成 Tauri 的 PNG、ICNS、ICO 及各平台尺寸，以及界面专用的无光晕 `src/assets/lumi-mark.svg`。应用图标使用 512×512 方形画布、448×448 黑色渐变圆角底板，琥珀标志居中，原始路径放大 1.12 倍，主体高度约 282px，四周保留留白。系统状态栏使用同一 L 与星芒形状的纯白透明图标，移除渐变与发光滤镜以保持小尺寸边缘清晰；关闭 macOS 模板着色，保留纯白设计。macOS 开发运行时加载更新后的 ICNS，发布包使用同一组图标。

避免大面积渐变、装饰图表和统计卡片。深色为品牌基准，浅色为补充对照方案，原始设计说明未规定浅色值。

ui-ux-pro-max 检索的 Minimalism & Swiss Style 适用于本项目；检索中的营销页结构与通用青绿色方案不适用。用户设计说明优先于检索建议。

## 信息结构

- 工作台：标题“你的工作台，由你来设计”与系统提示词卡片。
- 能力：Terminal、HTTP、MCP 统一列表。
- Skills：标准技能资源。
- Memory：个人与项目经验。
- 连接：AI 软件连接配置入口。
- 设置：外观主题。

## 交互

实际软件和效果页共用初始化工作台，主页只保留标题与提示词卡片。卡片提供“仅连接”“工作助手”“功能入口”三种类型，均显示固定内置模板。仅连接引导 AI 软件配置 Lumi MCP；工作助手和功能入口先配置 MCP，再分别设计个人工作台或组织功能入口。三份模板共用当前桌面会话的 Streamable HTTP 地址、端口和认证请求头，类型选择保存在本机，认证令牌只保留在内存中。复制成功或失败均提供文字反馈。当前没有 AI 自动写入工作台的接口，内置模板会要求 AI 在接口不可用时先给出设计方案，不声称已应用。

### MCP 连接配置

设置页提供 MCP 连接卡片，支持 Streamable HTTP／stdio 代理配置切换、查看与复制，以及实际 MCP 握手和工具发现自检。配置由主窗口专用 Tauri IPC 从 Core Supervisor 读取，与 Core 使用同一会话端口和令牌；HTTP、stdio 和应用内部 API 共用这个令牌。Lumi 重新启动后需要重新复制配置。网关可用信息来自 Core 启动握手，不再使用前端固定状态。浏览器效果页没有桌面 IPC 时提示从桌面应用获取配置，不生成虚构凭证。

桌面复制使用 [Tauri 官方系统剪贴板插件](https://v2.tauri.app/plugin/clipboard/)，只开放写入文本权限。浏览器效果页使用浏览器剪贴板 API，保留选中并手动复制的失败反馈。

效果页另有导航切换、类型筛选、资源详情、置顶、搜索（Command/Ctrl+K）、示例调用、新建资源与主题切换。示例资源不触发真实命令或外部服务。使用原生 dialog 保持焦点约束和 Escape 关闭，所有图标按钮提供可访问名称。

## 基础样式

- 背景、面板、文字和语义强调使用上方映射。
- 浅色窗口背景：`#f0f0ee`；主内容面板：`#ffffff`；内部卡片：`#f7f7f5`；文字：`#262629`；强调：`#875600`。
- UI 字体优先 Geist，技术内容优先 JetBrains Mono；未安装时回退系统字体，中文采用苹方。效果页不依赖远程字体。
- 56px 图标侧栏，44px 导航按钮；实际软件与效果页右侧无额外顶部栏；右侧卡片铺满可用区域，内部内容最大宽度 1152px。
- 4px 间距基线；2px 微元素、4px 控件、8px 内部容器圆角，主内容面板无外框圆角；交互反馈 120ms。
- 小屏折叠次要列，保持页面自然纵向滚动，支持减少动态效果设置。
