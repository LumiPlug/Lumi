# 知识库实施记录

## 当前实现：项目＋分支（2026-10-07）

当前采用 MCP v3 和数据库迁移 8，完整规则见 [项目分支知识库](KNOWLEDGE_BRANCHES.md)。按项目标识＋Git 分支分组，无 Git 默认 main；每组独立知识版本并记录 commit SHA。外部 AI 自行读取项目和 Git，通过 create/compare/build/write/publish 提交。Lumi 不再访问项目来源、提供授权/扫描或校验原文，引用只保存调用方提交的相对路径、内容哈希及位置。旧版本不兼容，用户已确认清空旧知识库。

以下来源存储调整、首次交付和验证记录是历史记录，不代表当前仍提供来源读取或授权能力。

依据 `KNOWLEDGE_BASE_DESIGN.md` 与 HTML PRD 落地。外部 AI 负责理解与生成，Lumi 负责授权、扫描、持久化、校验、发布、检索和浏览，不在 Core 内调用模型。

## 来源存储调整（2026-10-07）

此节替代旧方案中的来源快照规则：Lumi 只持久保存来源相对路径、规范化内容 SHA256、文件大小/行数及引用行号/片段哈希，不保存项目原文。MCP 的 `read_source` 在授权下临时读取当前文件，每页检查与扫描哈希一致；变化、删除或撤权即拒绝读取，不回退旧原文。`snapshotId` 为兼容现有引用保留的元数据 ID，不再代表文本快照。

来源查看和 `read(evidence)` 只返回引用元数据。生成知识及其历史版本继续可读，但无法离线复原历史项目原文。构建校验和发布前临时读取来源核对完整文件及引用哈希；变化或删除的引用必须更新/移除后再发布，保留旧知识版本不等于允许其过期引用进入新版本。

导出格式 v2 只包含知识与来源元数据；旧 v1 导入在内存校验后丢弃来源正文，导入库仍需重新绑定并授权本机目录。数据库迁移保留已有引用 ID，删除所有旧来源正文，并通过 secure_delete、VACUUM 和 WAL 截断清理数据库残留；外部备份或先前已导出的文件不在自动清理范围内。生成知识正文仍允许说明和代码示例，不将其当作项目备份。

验证：`pnpm check` 通过 19 个测试文件、149 个测试及 TypeScript、ESLint、Rust fmt/check/clippy。新增测试覆盖旧正文/WAL 清理、旧导入不存原文、变更分片拒绝、发布前来源复核和增量更新。真实 Core/MCP 浏览器联调在 1440px、390px 验证引用弹层只显示路径/行号/完整哈希且无原文行，导出不含原文。Tauri debug app 已构建。

用户确认清理并启动后，真实生产 Lumi 已完成迁移 7：旧快照表不存在，1,895 条来源元数据均无 text 字段，隐私清理队列为空，SQLite quick_check 为 ok。真实 MCP 契约版本为 2；LumiPlug（18 文档/18 节点）、Fatewise（16/16）、MagicNotice（23/26）仍为 v1，三个库的 evidence 读取均不含原文。原生 Lumi 已正常启动并显示 MagicNotice 图谱。

## 首个交付闭环

- Skills 下方知识库入口，项目卡片、生成知识目录、默认项目图谱与 Markdown 阅读、版本固定和来源快照。
- 主窗口独立主机凭证批准或拒绝目录请求，MCP 会话凭证不能授权目录。
- 持久扫描清单与 UTF-8 快照，默认排除敏感文件、依赖、构建目录与 Git 忽略内容；拒绝符号链接。
- 持久构建、令牌散列、批次幂等、乐观版本锁、引用与目录校验、原子发布。增量构建继承旧版本，删除需显式操作。
- 版本检索、归档、恢复、导入导出；SQLite FTS5 中文单字和二字词、代码标识符索引。
- 扩展共享 TreeView、GraphView、DocumentViewer、SourceViewer，并在 UI组件页预览。

## 阅读与授权行为

- 目录与文档选择支持键盘；关系清单支持 Tab、Enter/Space 选择节点，提供关系类型与推断标记。图谱使用 Cytoscape.js 和 Canvas，项目、模块、概念、符号映射既有主题语义色，不引入新的品牌或栅格素材。
- 文档和检索显示切换保持图谱挂载，清空检索后恢复视图模式、选中节点与阅读上下文。知识库、版本或邻域更换时重新创建图谱；窗口尺寸变化会重新适应布局。
- Canvas 容器宽度小于 720px 时以紧凑网格显示最多 6 个带标签节点，优先项目与模块并保留选中节点，关系使用曲线。关系清单保留本次 Core 返回的全部节点与关系，不受 6 节点显示限制。页面内容容器不超过 760px 时目录进入 Modal，不超过 1050px 时检查区位于图谱下方。
- 来源阅读展示发布版本引用的不可变快照，全局行号与引用范围高亮按 300 行分段浏览；展示快照不代表当前磁盘文件仍相同。
- 导入不会继承本机目录权限。导入知识和快照可立即阅读；继续读取目录或构建前，用户必须在主窗口重新选择并绑定本机目录、明确授权。未选择目录时授权按钮禁用，不自动绑定用户主目录。

## 边界

目录扫描由显式请求触发；自动文件监听、跨版本影响分析、细粒度客户端身份、团队 ACL、快照垃圾回收与知识库累计存储配额尚未实现。每次扫描最多读取 2,000 文件，单文件不超过 1 MiB，快照总量不超过 32 MiB；32 MiB 不是单库累计存储上限。每个发布版本最多 1,000 文档 / 2,000 节点 / 5,000 关系，内容不超过 16 MiB。

Core 项目全景最多返回 40 个节点、邻域最多 150 个节点，关系默认返回最多 300 条，并标记截断。关系清单完整呈现的是此次返回数据，不承诺一次展示全库所有关系。校验只证明快照和引用完整性，不证明 AI 的语义判断正确；实际理解与生成继续由外部 AI 经 Lumi MCP 完成。
