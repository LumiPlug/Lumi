# Lumi demo media

- [`lumi-demo.mp4`](lumi-demo.mp4): the 84-second, 1920×1080 Lumi demo, with English narration, Chinese and English captions, and original music.
- [`lumi-demo-cover.jpg`](lumi-demo-cover.jpg): a frame from the video's closing card, resized to 1280×720.

The product footage uses the real Lumi frontend connected to an isolated local Core with synthetic project data and dummy configuration values. The opening external AI conversation is labelled illustrative; the workbench was actually published through MCP. The labelled test-client screens show real MCP requests and responses, rather than a commercial AI application's conversation. Skills import and reading, tool execution and result retrieval, and two independent clients reading the same published knowledge version were verified.

The README uses a clickable cover and a link to the MP4 file. Playback or downloading depends on the viewer; no inline README player is assumed.
