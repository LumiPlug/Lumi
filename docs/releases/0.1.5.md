# Lumi 0.1.5 预览版

版本更新日期：2026-10-20。本次为本地代码提交与补丁版本递增，尚未推送或发布；继续沿用既有 GitHub preview 渠道，公开 tag 由 Desktop Build 运行序号生成。

- 设置新增“语言 / Language”，支持简体中文与 English，默认中文；自动保存后即时生效，无需重启。
- 导航、业务页面、共用组件、弹窗、提示词、操作反馈与辅助技术标签接入双语；日期、普通数字和英文单复数跟随语言。
- 桌面宿主持久化语言偏好；新建/重建窗口预载当前语言，已有运行窗口、应用控制的原生菜单和标题同步更新。
- 切换语言保留输入、页面状态和运行任务；保存失败保留原语言，复用顶部错误气泡并恢复选择框键盘焦点。
- 同步应用、Core、共享包、stdio 代理、主页 SDK 与模板版本为 0.1.5；主页格式 2、桥接协议 1 保持兼容。

验收与限制：

- 功能开发时已在 macOS WKWebView 和浏览器验证即时切换、重启、多窗口任务/日志保留、故障反馈、键盘焦点、双主题、窄窗口与英文弹窗。截图来自功能相同的 0.1.4 开发构建；本次补丁版本另做独立源码检查。见 [验收报告](../qa/2026-10-20-localization/README.md)。
- 用户名称、知识正文、导入的技能说明、第三方响应、原始日志与已有自定义工作台 HTML 保留原文。系统自行提供的标准菜单和对话框按钮由操作系统语言决定。
- Windows/Linux 尚未实机验收。托盘刷新路径已接入语言状态，macOS 应用菜单和运行窗口标题已经验收，托盘菜单尚未逐项点开验收。
- 本次仅包含中英文切换和版本更新；此前未提交的采集、技能扫描、工作台存储/权限等改动继续留在工作区。
- 未替换当前安装的 Lumi，未生成或发布新的发行安装包。macOS 沿用 ad-hoc 签名，Windows 发布者签名和自动更新仍未配置。
