# 主页 UI 与主题

主页布局和交互可自由设计，但应使用 Lumi 提供的当前主题变量（官方模板的 `theme.css` 给本地预览提供默认值）。SDK 连接后会自动同步深浅主题、CSS 变量和减少动态效果。不要把本机预览色值固定到真实主题上。

建议沿用宿主的常用控件 44px 最小高度、4px 控件圆角、8px 内容容器圆角、12px 气泡圆角，以及页面标题 26px、区块标题 18px、正文 14px、辅助文字 13px、标签 12px。窄窗口允许换行和滚动。

操作结果使用 `window.lumi.toast.show()`，不要在按钮下重复放结果或使用系统弹窗。校验失败聚焦首个错误字段并设置 `aria-invalid`、辅助描述；控件有可读名称、键盘焦点。动画尊重减少动态效果。背景和文字应保持主题下可读对比。
