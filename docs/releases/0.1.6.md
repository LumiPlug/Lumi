最终本地 `pnpm check` 通过52文件/416测试及类型/lint/Rust检查，前端构建和42项隔离合成回归通过，见 [验收记录](../qa/2026-10-20-qoder-cn-release/README.md)。

自动化使用纯合成来源及隔离账本，不读取真实会话、凭据或正式用量数据库。公司电脑的实时写入、实际性能、不同 Qoder 客户端版本及原生 WKWebView/WebView2 的现场显示仍待验收，不能由自动化替代。

macOS ARM64/Intel 与 Windows x64 安装包由现有工作流构建并校验包内 sidecar、源码提交和 SHA256 后发布。macOS 采用 ad-hoc 签名且未公证，Windows 无发布者签名；完整交互安装、升级与卸载仍需实机验收。
