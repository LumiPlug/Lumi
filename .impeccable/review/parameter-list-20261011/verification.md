# 参数固定滚动列表与按行显示图标

2026-10-11。必填 Switch 独立成列，删除列无可见标题且图标位于行尾。表头为外部可见、参数名、参数值、描述、必填，末列只有辅助技术删除名称。拖动图标仍在外部可见单元格，与勾选框横排。

鼠标悬停、行内键盘焦点或拖动状态显示拖动与删除图标；通过原生 span hidden 状态控制共用 Button／IconButton，始终预留36px位置，不新增控件视觉。焦点在行内时不会被鼠标移开隐藏；点击参数名后 Shift+Tab 两次可进入拖动手柄。滚动后按真实指向位置重新匹配激活行。

列表高度固定为共用控件高度8倍（288px），内部支持纵向和横向滚动，纵向滚动不移动下方 Shell 命令，滚动条留有位置。拖动优先滚动该列表，小窗口按外层裁剪后的可见边缘触发；浮层裁剪避开滚动条。UI组件参数表复用同一组合，规范同步。

pnpm check 通过：25文件、194项测试；类型、Lint、首页契约、Rust fmt/check/clippy 全部通过。前端和macOS调试应用构建通过，git diff --check、布局检测通过，保留既有构建提示。正常1120×820与窄720×560一轮检查后，针对滚动后的悬停更新及裁剪边缘自动滚动作一次批量修正，再确认。默认图标隐藏，行内聚焦显示，切换行时显示跟随行，输入框不位移；列表滚动到固定参数且 Shell 位置不变。窄窗口拖动 NAME 至第五项，Home恢复第一项，保存再次禁用。应用停留最终构建的示例配置页，窗口恢复正常尺寸与初始滚动位置。未保存验证修改或执行工具。

操作失误：第一次重启前AX显示保存可用，仍退出了应用，可能丢失当时未保存的配置草稿。已告知用户；无法恢复未知的内存草稿。数据库中的示例定义版本和哈希在整个任务前后相同，已保存定义未被改动。第二次重启已按保存禁用状态条件检查后才退出。
