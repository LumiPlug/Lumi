# Lumi 0.1.0 正式版

Lumi 将私有工具、Skills、项目知识、AI 工作台和浏览器能力集中到本机，通过统一 MCP 连接供 AI 客户端使用。正式版统一使用 0.1.0，配套 Lumi Browser 0.6.0；主页格式 2、桥接协议 1。

- 私有工具：Terminal、HTTP 和 MCP 工具共用配置、授权、执行、任务与日志链路。
- Skills：44 个默认软件分类，另支持显式配置的 Open Design；共享目录去重、来源合并、本地安装、归档及 MCP 检索与读取。
- 项目知识：按项目和分支组织文档、图谱及版本历史，通过 MCP 共享。
- 工作台：HTML/CSS/JavaScript 模板与浏览器 SDK，支持 AI 发布、源码导出、历史恢复，以及联网、CDN、表单、下载和弹窗。
- 存储：在入口脚本前预载 localStorage/sessionStorage 兼容层，支持项目隔离、串行写入、flush 确认和失败重试；SDK KV 单值 256 KiB，兼容层单值 1 MiB。
- 浏览器：39 个 MCP 工具，涵盖标签导航、页面操作、截图、PDF、文件选择、下载跟踪和按需网络/控制台诊断。
- AI 用量：本地来源采集与查询，包含 Qoder 国际版和中国版 JSONL、扫描阶段与覆盖进度。
- 桌面：英文与简体中文切换、深浅主题、共用搜索与分类筛选、托盘导航和 Core 控制；默认窗口 800×600，最小 720×560。

## 验证

Windows WebView2 自动化覆盖工作台 SDK KV 配额、localStorage/sessionStorage 写入与刷新恢复、flush 及宿主 DOM 隔离。跨平台源码检查、安装包构建和包内独立 sidecar 验证结果见本次发布的构建链接。

## 已知问题与安装说明

- 正式版版本号从此前 0.1.x 预览序列统一为 0.1.0。已安装 0.1.1–0.1.9 预览版时，安装器可能提示较旧版本；安装前退出 Lumi 并备份本地数据。升级、降版本覆盖及卸载尚未完成完整人工验收。
- macOS 使用 ad-hoc 签名且未公证；Windows 安装器和二进制无发布者签名，系统可能显示安全提示。自动更新尚未配置。
- macOS 需要 13.5 或更新版本；Windows x64 安装 WebView2 时可能需要网络。
- 托盘深浅主题、正常退出、多窗口、真实 AI 客户端及公司机 Qoder 采集仍有人工验收范围，详见 [Windows 验收记录](../qa/windows/automation.md)及 [AI 用量来源](../AI_USAGE_SOURCES.md)。
- 工作台设备能力受 WebView、origin 和系统授权约束；未 flush 的立即导航或异常退出不保证最后写入保存，兼容层不模拟 IndexedDB/Cookie。
- Skills 来源归属不代表客户端已安装或已启用；浏览器扩展的安装、操作兼容性和权限范围见 [浏览器集成说明](../BROWSER_USER.md)。
